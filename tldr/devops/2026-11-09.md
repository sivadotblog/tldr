### News & Trends

[### Docker and ActiveState Extending Secure Defaults to the Packages Developers Install (5 minute read)](https://www.docker.com/blog/docker-activestate-trusted-content?utm_source=tldrdevops)

Docker partnered with ActiveState to extend its trusted content standard from base images to packages installed through pip, npm, and Maven. ActiveState rebuilds components from source and promises fixes within 5 business days for critical CVEs.

[### What's next for Octopus Feature Flags (6 minute read)](https://octopus.com/blog/feature-flags-whats-next?utm_source=tldrdevops)

Octopus Feature Flags leave public preview for Octopus Cloud and arrive in self-hosted Octopus 2027.0, with rules-based targeting and phased automated rollouts. Existing flags require updated client SDKs before upgrading.

### Opinions & Tutorials

[### How we halved DNS build delay and cut memory use by 85% (18 minute read)](https://blog.cloudflare.com/dns-targeted-zone-builds/?utm_source=tldrdevops)

Cloudflare stopped rebuilding entire DNS zones for settings changes by identifying which records could be affected and grouping pending work for the same zone. Peak memory fell from 79 GiB to 12 GiB, and shorter waits between pipeline stages brought median build completion time down from 7.7 to 3.3 seconds.

[### Well, That Wasn't Fun: October 16 '26 (7 minute read)](https://fly.io/blog/well-that-wasnt-fun/?utm_source=tldrdevops)

Fly.io patched and rebooted its entire fleet over 10 hours in response to CVE-2026-99999, a Linux kernel bug that allowed guest VMs to read host memory. The vulnerability allowed an attacker to control two bytes of an IPv4 header, leading to firewall bypasses and out-of-bounds reads. Fly.io advises customers who sent unencrypted traffic between October 15 and 17 to rotate their credentials.

[### How to Import Existing Resources to OpenTofu [Tutorial] (15 minute read)](https://spacelift.io/blog/opentofu-import?utm_source=tldrdevops)

Spacelift compares the OpenTofu import CLI command with import blocks and recommends blocks because they appear in plan and apply. The tutorial covers for\_each imports, the identity argument, and experimental config generation.

[### Production access shouldn't outlive the task (Sponsor)](https://fandf.co/4iGMVco)

A quick fix shouldn't require permanent admin access. With [Teleport](https://fandf.co/4iGMVco), engineers can request temporary access to servers, Kubernetes clusters, and databases. Approve requests through tools like Slack, then let privileges expire automatically.

[### Llama-modchip (GitHub Repo)](https://github.com/synchopate/llama-modchip?utm_source=tldrdevops)

Llama-modchip runs the 284-billion-parameter DeepSeek-V4-Flash on a pure 64GB CPU with no GPU. It achieves up to 14.7 tokens per second using SwiGLU-H2 compression and cache optimizations. The tool also supports other models, including NVIDIA-Nemotron-3.5-30B-A3B at up to 111 tokens per second.

[### Claude-quickstarts (GitHub Repo)](https://github.com/anthropics/claude-quickstarts?utm_source=tldrdevops)

Claude-quickstarts is a collection of projects designed to help developers build deployable applications using the Claude API. The repository includes examples for use cases like a customer support agent, a financial data analyst, and various computer use demos.

Datadog Online Experiments compares AI agent variants on live traffic using evaluation scores alongside latency, cost, and error metrics. In an internal test, GPT-6 Luna cut estimated cost by 44.3 percent versus GPT-5.6 Luna with nearly identical quality scores.
