### News & Trends

[### Spacelift Brought Scale to Your IaC Provisioning. Now We're Automating Everything That Happens After. (4 minute read)](https://spacelift.io/blog/full-stack-infrastructure-orchestration?utm_source=tldrdevops)

Spacelift is expanding from IaC provisioning into Day 2 operations with Spacelift Flows. It also renamed its IaC and GitOps offering to 'Spacelift Deploy' and bundles it with the Spacelift Intelligence assistant in one control plane.

[### Cloudflare Services for Private Origins Is Now Generally Available (5 minute read)](https://blog.cloudflare.com/private-origins-public-to-private/?utm_source=tldrdevops)

Cloudflare can now route public requests to private origin IPs over existing Cloudflare One connectivity while applying WAF, caching, bot management, and Workers. Origins retain private addresses without inbound firewall exceptions. Setup requires account enablement, supported connectivity, and appropriate return routes.

[### Grafana 13.3 release: manage variables across dashboards, share findings with Notebooks, a UI refresh, and more (6 minute read)](https://grafana.com/blog/grafana-13-3-release-all-the-latest-features/?utm_source=tldrdevops)

Grafana 13.3 adds cross-dashboard variables and Notebooks, both in public preview, plus the first phase of a visual refresh. It also brings Assistant dashboard plans and a generally available Undo turn option for reverting Assistant edits.

### Opinions & Tutorials

[### How to troubleshoot GKE workloads faster with VPC Flow Logs (5 minute read)](https://cloud.google.com/blog/products/containers-kubernetes/using-vpc-flow-logs-to-troubleshoot-gke-workloads/?utm_source=tldrdevops)

Google Cloud shows how GKE metadata in VPC Flow Logs gives workload-level attribution for network traffic without agents or sidecars. It walks through three Flow Analyzer examples on the Online Boutique demo.

[### Default to serverless for AI agents, then let production data decide what moves (10 minute read)](https://www.datadoghq.com/blog/serverless-ai-agents/?utm_source=tldrdevops)

Datadog argues that serverless should be the first execution model teams evaluate for AI agents. It cites a study of over 35,000 coding agent sessions where LLM or tool calls filled only 20% of the median session.

[### What's actually running under your EC2 instance? (Sponsor)](https://aws.amazon.com/ec2/nitro/?trk=221ff974-e04d-4fa3-a095-9a0b04c5ff02&amp;sc_channel=el)

Meet the [AWS Nitro System](https://aws.amazon.com/ec2/nitro/?trk=221ff974-e04d-4fa3-a095-9a0b04c5ff02&sc_channel=el), the foundation for Amazon EC2 instances. [### Vorssaint (GitHub Repo)](https://github.com/vorssaint/vorssaint-utils?utm_source=tldrdevops)

Vorssaint is a free and open-source macOS menu bar toolkit that replaces dozens of paid utility apps. It offers per-app volume controls, window snapping, a clipboard history, and system monitors. The tool runs locally with no account, telemetry, or subscription required.

[### OpenMAIC (GitHub Repo)](https://github.com/THU-MAIC/OpenMAIC?utm_source=tldrdevops)

OpenMAIC is an open-source AI platform that transforms documents into interactive classroom experiences with AI teachers, slides, and simulations. It supports over 20 providers, including OpenAI, Anthropic, and local options like Ollama.

### Miscellaneous

[### How GKE networking scales to support high densities of concurrent AI agents (4 minute read)](https://cloud.google.com/blog/products/networking/gke-networking-dataplane-for-large-agentic-ai-workloads/?utm_source=tldrdevops)

Google Cloud explains how GKE Dataplane V2 avoids Cilium's 65,536 identity limit for high-density agent workloads by moving high-cardinality pod labels to annotations. The post reports 300 sandboxes per second at sub-second latency.

[### Do the math: How we took over ChatGPT accounts (10 minute read)](https://www.parameter.ai/labs/we-found-a-gap-at-openai?utm_source=tldrdevops)

Researchers found a vulnerability that allowed them to take over ChatGPT accounts just by sending a victim a link. The exploit chain combined a MathLive keyboard feature and the HTML Preview to bypass the sandbox, allowing malicious code to run as chatgpt.com and access private conversations. OpenAI fixed the issue on October 26 and classified the report as P1.

[### Trace voice agents with Datadog Agent Observability (5 minute read)](https://www.datadoghq.com/blog/agent-observability-voice-agent/?utm_source=tldrdevops)

Datadog Agent Observability now captures audio, transcripts, token usage, and tool calls for voice agents built on the OpenAI Realtime API. It also adds tracing for Amazon Nova 2 Sonic, with ElevenLabs Realtime support planned for ddtrace 4.17.0.
