### News & Trends

[### Alpine Linux Security Advisory: OpenSSH-server password authentication bypass (5 minute read)](https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/?utm_source=tldrdevops)

A vulnerability in Alpine Linux's openssh-server package allows attackers to bypass password authentication and log in without knowing any password. The flaw affects releases 3.16 through 3.24 and allows remote access if the system has an account with no password set. Users should update openssh and restart sshd or disable password logins immediately.

[### Powering open infrastructure for autonomous agents (12 minute read)](https://cloud.google.com/blog/products/containers-kubernetes/open-infrastructure-for-autonomous-agents-comes-to-cncf/?utm_source=tldrdevops)

Google donated Agent Substrate, gVisor, and OpenRL to the CNCF Sandbox and announced the general availability of Agent Substrate on GKE. Agent Substrate decouples stateful agent sessions from compute to restore idle sessions in under 500 milliseconds. The project achieves 10x standard container density and performs over 500 suspend and resume activations per second.

### Opinions & Tutorials

[### Running Production With Zero Stored Logs (6 minute read)](https://cloudnativenow.com/contributed-content/running-production-with-zero-stored-logs/?utm_source=tldrdevops)

This post describes how to run a K3s platform of more than 15 microservices with no centralized log collection, relying on filtered Prometheus metrics and temporary verbose logging. It notes trade-offs, including the need to anticipate questions and unsuitability for audits requiring immutable trails.

[### When the Kubernetes API went silent: A three-layer networking mystery (8 minute read)](https://cloud.google.com/blog/products/networking/the-three-layer-gke-network-mystery?utm_source=tldrdevops)

Google traced intermittent GKE API timeouts to three interacting failures: Private Service Connect reordered packets, Envoy kept half-closed sockets open, and a Linux TCP bug prevented those sockets from closing. Simultaneous packet captures at multiple points exposed the reordering, and a Linux kernel patch fixed the underlying TCP bug.

[### Docker Urges Isolation and Governance for AI Agent Security (5 minute read)](https://www.infoq.com/news/2026/11/docker-ai-agent-security/?utm_source=tldrdevops)

Docker identifies five risks of autonomous AI agents, including prompt injection, credential exposure, and data exfiltration. It recommends isolation and governance through Docker Sandboxes and AI Governance rather than model improvements alone.

[### agent-browser (GitHub Repo)](https://github.com/vercel-labs/agent-browser?utm_source=tldrdevops)

agent-browser is a native Rust CLI that gives AI agents a browser they can drive one shell command at a time. It reads pages as a compact accessibility tree and allows agents to interact with elements through refs. The tool supports Chrome for Testing, Mobile Safari, and various cloud browser providers.

[### Auto Ontology (GitHub Repo)](https://github.com/NVIDIA/auto-ontology?utm_source=tldrdevops)

NVIDIA Auto Ontology is a Python framework for building semantic, graph-based reasoning layers over enterprise data. The open source library builds context layers from metadata to enable deterministic query generation and more explainable AI for LLM workflows. It exposes this context to agents via MCP, CLI, and API access.
