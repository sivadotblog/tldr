### News & Trends

[### Kubernetes v1.37: Storage Version Migration Enabled by Default (3 minute read)](https://kubernetes.io/blog/2026/08/31/kubernetes-v1-37-storage-version-migration-ga/?utm_source=tldrdevops)

Storage version migration (SVM) is now generally available in Kubernetes v1.37, stable and enabled by default across all clusters running that version. The feature lets cluster administrators migrate stored API resources to a current storage version by creating a declarative StorageVersionMigration object, which the built-in control plane controller then handles automatically. Previously, admins had to rely on manual kubectl scripts or a separate out-of-tree component called kube-storage-version-migrator.

[### Wasmi 2.0 - Engineering of the Fastest Wasm Interpreters (23 minute read)](https://wasmi-labs.github.io/blog/posts/wasmi-v2.0/?utm_source=tldrdevops)

Wasmi 2.0 is roughly 2.2× faster than Wasmi 1.0 across its benchmark suite, largely through a redesigned interpreter that adds threaded-code dispatch, accumulator registers, and lower-overhead instruction handling. The release also preserves fast startup, adds options to reduce binary size, and includes stable fuel metering, deterministic WebAssembly support, and an improved CLI.
