### News & Trends

[### Bridging Alloy and OpenTelemetry: the OTel engine is now in Public Preview (8 minute read)](https://grafana.com/blog/bridging-alloy-and-opentelemetry-the-otel-engine-is-now-in-public-preview/?utm_source=tldrdevops)

Grafana Alloy's OpenTelemetry engine is now in Public Preview as of Alloy v1.21.0. It runs standard OpenTelemetry Collector YAML configuration and supports Fleet Management for remote configuration. Users can run the OTel engine alongside the default engine or switch between them using an environment variable.

[### Lakebase Postgres is now generally available on Google Cloud (11 minute read)](https://www.databricks.com/blog/lakebase-postgres-now-generally-available-google-cloud?utm_source=tldrdevops)

Lakebase Postgres is now generally available on Google Cloud as a fully managed, serverless database. It includes autoscaling, scale to zero, instant branching, and point-in-time recovery to help teams build and ship faster without managing database infrastructure. Operational and analytical data share the same storage format.

### Opinions & Tutorials

[### Shopify Overexposed Scans GKE Ingresses and Cloud Run for Exposure (4 minute read)](https://www.infoq.com/news/2026/11/shopify-kubernetes-ingresses/?utm_source=tldrdevops)

Shopify Overexposed is an internal scanner that finds GKE Ingresses and Cloud Run services reachable without authentication. A rebuild on GCP Cloud Asset Inventory plus an anonymous HTTP probe cut inconclusive Ingress verdicts by about 80%.

[### The hidden latency inside your database (8 minute read)](https://planetscale.com/blog/the-hidden-latency-inside-your-database?utm_source=tldrdevops)

PlanetScale Metal uses locally attached NVMe storage to eliminate network latency between compute and disk. This architecture avoids the IOPS limits of network-attached storage like EBS, where defaults are often capped at 3,000 IOPS. Benchmarks show an instance with local NVMe storage costs $551.15 per month compared to $1,513.82 for a comparable EBS setup.

[### Deep dive: Auto scaling response times on Amazon ECS (12 minute read)](https://aws.amazon.com/blogs/containers/deep-dive-auto-scaling-response-times-on-amazon-ecs/?utm_source=tldrdevops)

Amazon ECS now offers high-resolution CPU and memory metrics published every 20 seconds for target tracking, allowing services to detect and respond to load changes faster than the default 60-second resolution. AWS benchmarks show time to trigger scale-out fell 76%, from 363 seconds to 86 seconds, and SLA breach time on Fargate decreased 69% in gradual ramp tests.

[### Floci (GitHub Repo)](https://github.com/floci-io/floci?utm_source=tldrdevops)

Floci is a free, open-source local AWS emulator for development, testing, and CI that works without a cloud account or auth token. It supports standard tools like Terraform and the AWS CLI, and Lambda or RDS workloads run in real Docker containers for higher fidelity than mocks. The project also acts as a drop-in replacement for LocalStack.

[### Agent-Desktop (GitHub Repo)](https://github.com/vercel-labs/agent-desktop?utm_source=tldrdevops)

Agent-Desktop is a CLI that enables AI agents to see and operate desktop applications on macOS, Windows, and Linux through the OS accessibility tree. It reads the accessibility tree as JSON, allowing agents to interact with elements without using screenshots or pixel matching.
