### News & Trends

[### Spacelift Integrates with Cursor Origin (3 minute read)](https://spacelift.io/blog/spacelift-cursor-origin-integration?utm_source=tldrdevops)

Agent-driven infrastructure changes now flow through Spacelift using a registered Origin app with a signing key, so the same OPA policies and approvals apply. A cited report says 76% would apply AI-generated Terraform with little review.

[### Cloudflare Logpush Transformers (7 minute read)](https://blog.cloudflare.com/transformers-on-logpush/?utm_source=tldrdevops)

Cloudflare Transformers use SQL to filter, redact, and reshape logs before export. The feature is now generally available on all plans.

[### Amazon S3 is now available on the Vercel Marketplace and v0 by Vercel (4 minute read)](https://aws.amazon.com/blogs/aws/amazon-s3-vercel-marketplace-v0/?utm_source=tldrdevops)

Developers on Vercel can now provision Amazon S3 storage, including S3 Tables and S3 Vectors, directly from the Vercel Marketplace and v0. The integration handles connection configuration automatically and supports three workloads: everyday storage, analytics, and AI. Users pay standard Amazon S3 pricing for the resources they use, and new AWS accounts created through Vercel receive $100 in credits valid for six months.

### Opinions & Tutorials

[### Sequences and Other Volatiles in Neki (12 minute read)](https://planetscale.com/blog/neki-volatile-expressions?utm_source=tldrdevops)

Distributing PostgreSQL queries across shards gets complicated when functions depend on time or generate sequence values. Neki coordinates sequence allocation through its router and preserves how often expressions execute, preventing query optimizations from producing duplicate IDs or changing SQL behavior.

[### Inside Hyperdrive: How We Solved a Rare MySQL Caching Bug (10 minute read)](https://blog.cloudflare.com/hyperdrive-mysql/?utm_source=tldrdevops)

A rare Hyperdrive bug returned empty MySQL results when two components shared a cache but encoded responses using different protocol capabilities. Cloudflare traced the failures to an assumption inherited from its Postgres implementation and fixed them by storing responses in a canonical format before translating them for each client.

[### Tokenspeed (GitHub Repo)](https://github.com/lightseekorg/tokenspeed?utm_source=tldrdevops)

TokenSpeed is an open-source LLM inference engine designed for agentic workloads, offering TensorRT-LLM-level performance and vLLM-level usability. It is the first inference engine to separate the control plane, implemented in C++, from the execution plane, implemented in Python. The project is backed by the non-profit LightSeek Foundation with support from vendors including NVIDIA and AMD.

[### Xerj (GitHub Repo)](https://github.com/xerj-org/xerj?utm_source=tldrdevops)

XERJ is a local AI search tool that indexes code, docs, logs, and PDFs for search and RAG. It uses 40x fewer tokens than grep and reduces a coding agent's output tokens by 2.7x in controlled studies. The tool is compatible with the Elasticsearch API and runs on Linux, macOS, and Windows.

[### Pulumi ESC now issues OIDC tokens for any service (5 minute read)](https://www.pulumi.com/blog/esc-oidc-tokens-for-any-service/?utm_source=tldrdevops)

Pulumi ESC environments can now mint short-lived OpenID Connect (OIDC) tokens for any service that accepts one. The new fn::open::oidc provider generates tokens that expire within one hour, eliminating the security risks associated with storing long-lived API keys. Developers can use these tokens to authenticate with services like Anthropic, Cloudsmith, JFrog Artifactory, and Aembit without storing static credentials. The feature is available now in every Pulumi Cloud organization.
