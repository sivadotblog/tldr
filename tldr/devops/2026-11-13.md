### News & Trends

[### Solo.io Makes Enterprise Agent Substrate and kagent Generally Available (2 minute read)](https://cloudnativenow.com/kubecon-cloudnativecon-north-america-2026/solo-io-makes-enterprise-agent-substrate-and-kagent-generally-available/?utm_source=tldrdevops)

Solo.io released enterprise editions of Agent Substrate and kagent, which suspend idle agent sessions and resume them on demand. Agentgateway enforces identity and policy on traffic, and OutSystems and Swissquote run the stack in production.

[### Critical RCE Vulnerability in Apache HTTP Server: Everything You Need To Know (3 minute read)](https://www.wiz.io/blog/cve-2026-119618-rce-apache-http-server-vulnerability?utm_source=tldrdevops)

A critical RCE vulnerability in Apache HTTP Server's HTTP/2 module stems from a race condition in the assign\_headers() function. Wiz data shows 64% of cloud environments have vulnerable resources. Organizations should upgrade to version 2.4.71 or later, or disable HTTP/2 support, to address the flaw.

### Opinions & Tutorials

[### Beyond Test Cards: A Fake Payment Provider for Testing at Scale (14 minute read)](https://eng.lyft.com/beyond-test-cards-a-fake-payment-provider-for-testing-at-scale-c69dddadb115?source=rss----25cd379abb8---4&amp;utm_source=tldrdevops)

Lyft built a Fake Payment Provider that supports complex failure scenarios like partial authorization, latent captures, and refunds, which standard test cards cannot model. It embeds scenario logic directly into the payment token, allowing simulated users to test specific retry and fallback paths safely in both staging and production environments.

[### Don't just flag it, fix it: How to run CodeMender in your pull requests (5 minute read)](https://cloud.google.com/blog/products/identity-security/how-to-run-codemender-in-your-pull-requests/?utm_source=tldrdevops)

Google Cloud architects describe a reference architecture that connects the CodeMender security agent to Git pull requests on Cloud Run. Slash commands verify and fix findings, and short-lived OIDC tokens avoid stored keys.

[### How we migrate TBs from Heroku without logical replication (11 minute read)](https://planetscale.com/blog/migrate-from-heroku-to-planetscale?utm_source=tldrdevops)

PlanetScale built an open-source Heroku Migrator to move databases up to multiple terabytes without logical replication. It uses Bucardo for trigger-based replication to keep data in sync during the migration. The tool splits the process into data transfer and index rebuild phases to increase copy speeds by roughly five times.

[### Open Cluster Management (OCM) becomes a CNCF Incubating Project (5 minute read)](https://www.cncf.io/blog/2026/11/10/open-cluster-management-ocm-becomes-a-cncf-incubating-project/?utm_source=tldrdevops)

The CNCF Technical Oversight Committee accepted Open Cluster Management as an incubating project. OCM manages Kubernetes clusters across cloud, on-premises, and edge, and eBay uses it with Argo CD across more than 190 clusters.

[### What an Independent Threat Model Found in Linkerd, and What You Should Do Next (7 minute read)](https://linkerd.io/2026/11/10/what-an-independent-threat-model-found-in-linkerd-and-what-you-should-do-next/?utm_source=tldrdevops)

An independent threat model of open-source Linkerd identified 30 threats, 28 of which were categorized as medium or high. Only one finding is a software bug, which maintainers fixed in February 2025. The rest stem from default settings and configuration choices. This guide maps every threat to MITRE ATT&CK and NIST 800-53 frameworks.
