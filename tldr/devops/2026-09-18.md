### News & Trends

[### Kubernetes v1.37: Pod-Level Resource Managers graduated to Beta (2 minute read)](https://kubernetes.io/blog/2026/09/15/kubernetes-v1-37-pod-level-resource-managers-beta/?utm_source=tldrdevops)

The Pod-Level Resource Managers feature has graduated to Beta status in Kubernetes v1.37. This enhancement allows the Kubelet to use pod-level resource declarations when making hardware placement decisions. It solves a previous limitation where operators had to choose between dedicating physical cores to sidecars or forfeiting NUMA alignment.

[### Salesforce staggers back to feet after global outage (4 minute read)](https://www.theregister.com/saas/2026/09/16/salesforce-staggers-back-to-feet-after-global-outage/5296800?utm_source=tldrdevops)

Salesforce experienced an hours-long global outage affecting hundreds of instances, causing severe delays, intermittent errors, and inaccessible services, due to requests stalling on an internal login service and exhausting server resources. A validated fix was deployed fleetwide, but some instances required manual restarts and continued experiencing scheduled-job failures.

### Opinions & Tutorials

[### How to automate Docker Registry creation with Harness Pipelines and Terraform (14 minute read)](https://www.harness.io/blog/how-to-automate-docker-registry-creation-with-harness-pipelines-and-terraform?utm_source=tldrdevops)

Harness demonstrates a three-stage CI/CD pipeline that uses Terraform to dynamically provision a unique Docker virtual registry and Docker Hub upstream proxy, builds and pushes an image, then deploys it to Kubernetes with rolling updates and automatic rollback. Output variables and Harness expressions connect resources across stages without hardcoding.

[### Running OpenBao on Kubernetes with a CloudNativePG PostgreSQL backend (9 minute read)](https://www.cncf.io/blog/2026/09/16/running-openbao-on-kubernetes-with-a-cloudnativepg-postgresql-backend/?utm_source=tldrdevops)

OpenBao and CloudNativePG can manage infrastructure secrets on Kubernetes without vendor lock-in by using certificate authentication and synchronous replication. OpenBao uses the CloudNativePG PostgreSQL cluster as an encrypted key-value store, and a schema-init job revokes default public permissions to lock down the database. CloudNativePG automatically renews client certificates every 90 days, but OpenBao requires a rolling restart to load the new files. The setup runs three OpenBao replicas and three Postgres instances across separate nodes.

[### I don't like LLMs (4 minute read)](https://martinfowler.com/articles/2026-dont-like-llms.html?utm_source=tldrdevops)

LLMs can be highly useful while still being unpleasant to interact with because they present fabricated and correct information with the same confident, human-like tone. AI agents also reflect the values and culture of the companies that build them, making trust, behavior, and interaction design important alongside raw model capability.

[### Getting started with runtime security and Falco (11 minute read)](https://webflow.sysdig.com/blog/intro-runtime-security-falco?utm_source=tldrdevops)

[### HarnessTax: How Much Does the Harness Matter for Coding Agents? (8 minute read)](https://harnesstax.github.io/?utm_source=tldrdevops)

Coding-agent harnesses such as Claude Code, Codex CLI, and Pi can produce similar task success rates while using dramatically different amounts of tokens and money. Across 21 model–harness combinations on SWE-bench Lite and Terminal-Bench 2.0, harness choice changed cost by as much as 5×, and the model provider's own harness was not consistently the most efficient option.
