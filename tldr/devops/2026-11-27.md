### News & Trends

[### The best Octopus yet (7 minute read)](https://octopus.com/blog/the-best-octopus-yet?utm_source=tldrdevops)

Octopus Deploy redesigned its interface with instance-wide search, regrouped navigation, and a searchable REST API reference covering about 1,800 endpoints. The update is rolling out to Octopus Cloud now and will reach self-hosted customers in Octopus Server 2027.0 on December 2.

[### Terraform introduces tfpolicy support for Stacks, SCIM support, and more (6 minute read)](https://www.hashicorp.com/blog/terraform-introduces-tfpolicy-support-for-stacks-scim-support-and-more?utm_source=tldrdevops)

HashiCorp made HCL-based policy for Terraform Stacks generally available, along with multi-deployment group orchestration and agent-ready CLI commands with JSON output. SCIM 2.0 provisioning also reached general availability for HCP Terraform Standard and Premium.

### Opinions & Tutorials

[### Dogfooding Checks and Workspaces: Hard lessons from 3,000 repos (7 minute read)](https://www.chainguard.dev/unchained/dogfooding-checks-and-workspaces-hard-lessons-from-3-000-repos?utm_source=tldrdevops)

Chainguard moved thousands of daily builds off GitHub Actions onto its own microVM infrastructure to prevent release queues from stalling during cloud outages. CVE-remediation agents now run at 97 to 98 percent weekly success rates, with package bumps auto-merging about 99 percent of the time.

[### Dedicated Clusters per Workload: When Shared Stops Paying (5 minute read)](https://cloudnativenow.com/contributed-content/dedicated-clusters-per-workload-when-shared-stops-paying/?utm_source=tldrdevops)

Shared Kubernetes clusters are the right default, but some workloads need dedicated ones. Blast radius, network reach, and regulatory boundaries justify separation, though duplicated components and upgrades add cost teams often underestimate.

### Miscellaneous

[### Please don't give the robot my SSH keys: How to keep AI out of trouble (3 minute read)](https://thenewstack.io/teleport-agent-delegated-identity/?utm_source=tldrdevops)

Teleport field CTO Boris Kurktchiev explains delegated identity for AI agents. Agents start without access, request only what a task needs, and leave an audit trail linking their actions to the person who assigned the work.

[### How the data center shapes the AI workload (4 minute read)](https://www.nscale.com/blog/how-the-data-center-shapes-the-ai-workload?utm_source=tldrdevops)

Network topology shapes how multi-node GPU workloads distribute computation and move data. Larger NVLink domains change where communication-heavy parallelism can run, while SHARP performs collective aggregation inside switches. Nscale's engineering overview connects these architectural choices to practical questions about GPU placement, fabric configuration, and cluster validation.

[### Why Your CI Pipeline Failed: Decoding Exit Status 1 & OOM (9 minute read)](https://www.harness.io/blog/your-ci-pipeline-just-failed-with-system-failure?utm_source=tldrdevops)

Harness shows how identical exit status 1 failures in parallel CI stages hid different root causes. A full disk, an out-of-memory kill, and a timed-out database wait each needed different fixes, so teams should read stage logs rather than banners.
