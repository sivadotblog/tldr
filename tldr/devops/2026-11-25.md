### News & Trends

[### OpenAI and Cisco introduce Shirudo (5 minute read)](https://openai.com/index/introducing-shirudo?utm_source=tldrdevops)

Shirudo is an open-source runtime that protects running Linux systems without requiring patches or restarts. It uses eBPF to block vulnerable code paths, allowing services to continue operating while security teams apply temporary safeguards. OpenAI and Cisco released Shirudo under a BSD 2-Clause license.

[### Kubernetes v1.38 Sneak Peek (5 minute read)](https://kubernetes.io/blog/2026/11/23/kubernetes-v1-38-sneak-peek/?utm_source=tldrdevops)

Kubernetes v1.38 is expected to change how kubelets obtain their cgroup driver, requiring container runtimes to report it through CRI by default. The release also removes kubectl's WebSocket opt-out environment variables and drops the deprecated name alias from stable kuberc credential-plugin allowlists. Operators should check runtime compatibility and continue migrating nodes to cgroup v2 ahead of its eventual requirement.

### Opinions & Tutorials

[### Holding the Door for Agents (8 minute read)](https://fly.io/blog/holding-the-door-for-agents/?utm_source=tldrdevops)

Agents now perform at least 55% of deployments to Fly.io, and bots recently surpassed humans in web traffic for the first time. Fly.io now supports auth.md for agent signup and the Machine Payments Protocol, which lets agents top up accounts without human intervention.

[### Probing DNS at Cloudflare (9 minute read)](https://blog.cloudflare.com/probing-dns-at-cloudflare/?utm_source=tldrdevops)

A scheduling bug left DNS record changes unpublished for hours while Cloudflare's service health checks stayed green. Cloudflare extended its Flamingo testing framework to continuously update timestamped TXT records and query authoritative nameservers and 1.1.1.1 from every data center. These propagation measurements now inform release and rollback decisions.

[### Why you shouldn't do application-level sharding (19 minute read)](https://planetscale.com/blog/why-you-shouldnt-do-app-level-sharding?utm_source=tldrdevops)

Application-level sharding embeds routing logic in application code, but creates operational burdens like difficult resharding and cross-shard queries. The article details how companies like Intercom, Etsy, and Slack faced complexities including manual data migrations, reliance on single lookup tables that risked outages, and underutilized infrastructure to avoid difficult splits.

[### Last30days-skill (GitHub Repo)](https://github.com/mvanhorn/last30days-skill?utm_source=tldrdevops)

Last30days-skill is an AI agent that researches topics across Reddit, X, YouTube, and other platforms to synthesize a summary. It ranks results by social engagement metrics like upvotes and likes rather than SEO.

[### sofka (GitHub Repo)](https://github.com/nklmilojevic/sofka?utm_source=tldrdevops)

sofka is a Kubernetes terminal interface written in Rust with built-in Flux CD and Argo CD actions, custom resource browsing, and background port forwarding.
