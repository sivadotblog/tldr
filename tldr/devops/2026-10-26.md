### News & Trends

[### Expanding Claude availability and deployment choice on Google Cloud (2 minute read)](https://cloud.google.com/blog/products/ai-machine-learning/expanding-claude-availability-on-google-cloud/?utm_source=tldrdevops)

Google Cloud now offers an Anthropic-managed deployment option for Claude models alongside its Google-managed one. Both provide the same models on day zero at the same pricing. The Anthropic-managed option adds immediate access to Claude Platform features such as Managed Agents.

[### AWS Continuum for code vulnerabilities is now generally available (1 minute read)](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-continuum-for-code-vulnerabilities-is-now-generally-available?utm_source=tldrdevops)

AWS has made Continuum for code vulnerabilities generally available. It builds a context graph of an AWS environment, tests findings for exploitability in a sandbox, and opens pull requests with patches. Teams start in Learn mode and can move to Enforce mode.

[### Broccoli2shell: Everything You Need To Know About The Critical Brotli Decoder Vulnerability (5 minute read)](https://www.wiz.io/blog/cve-2026-111497-brotli-rce-node-js?utm_source=tldrdevops)

CVE-2026-111497, also known as Broccoli2Shell, is a critical vulnerability in the Brotli decompression library that allows remote code execution. The flaw affects Node.js, Bun, and Envoy Proxy. Wiz data shows 91% of cloud environments have vulnerable resources. Organizations should apply security updates and rebuild affected workloads.

### Opinions & Tutorials

[### Detecting and mitigating ZDI-CAN-33367 and five other Linux flaws (8 minute read)](https://webflow.sysdig.com/blog/detecting-and-mitigating-zdi-can-33367-and-five-other-linux-flaws?utm_source=tldrdevops)

A working root exploit for Linux kernel bug ZDI-CAN-33367 is public before a CVE or fix is available. TuxCare reproduced the proof of concept for local privilege escalation on Ubuntu, Debian, and AlmaLinux. A separate patch for the flaw is reviewed but not merged, and none of the six disclosed bugs has a CVE ID yet.

[### Shard design doesn't start from your tables (7 minute read)](https://planetscale.com/blog/shard-groups-the-unit-of-co-location?utm_source=tldrdevops)

Neki "shard groups" let users co-locate related tables like customers and orders on the same physical cluster to keep joins and transactions local. Reference tables replicate lookup data to every shard, while global secondary indexes support queries that lack the shard key.

[### Origin Range Requests: Serving Large Files Without Range-Request Tuning (9 minute read)](https://blog.cloudflare.com/origin-range-requests/?utm_source=tldrdevops)

Cloudflare rebuilt range-request caching in Pingora to coordinate partial downloads across cached data and in-flight origin fetches. The redesign roughly halved R2's p99 time to first byte and eliminated customer-managed range sizes, while a follow-up improvement reduced tiered-cache traffic for R2 and similar workloads by about 6%.

Coolify is an open-source, self-hostable PaaS alternative to Vercel, Heroku, and Netlify. It allows users to deploy static sites, databases, and full-stack applications on their own servers. The tool offers more than 360 one-click services and automatic HTTPS certificates.

[### QuestDB 10.1: Fresher Data, Less I/O, and More Analysis in SQL (12 minute read)](https://questdb.com/blog/questdb-10-1-release/?utm_source=tldrdevops)

QuestDB 10.1 adds optional merge-append partitions that reduce rewriting when late data arrives, with background compaction reclaiming obsolete rows. On QuestDB's public demo, enabling the feature reduced rows written per ingested row from about 440 to 8. The release also adds exact percentiles and SQL subsampling.

### Miscellaneous

[### Scale isn't one number: three ways a Kubernetes control plane runs out of room (8 minute read)](https://thenewstack.io/scaling-kubernetes-control-planes/?utm_source=tldrdevops)

Kubernetes control planes run out of room in three independent ways: node count, object churn, and resident state. Joe Betz of Google describes four seams, including storage routing and cache residency, and a recipe ladder built from stock upstream components. Some seams still have upstream gaps.

[### Railway Preliminary Report: Oct 21st Security Incident (7 minute read)](https://blog.railway.com/p/preliminary-report-october-security-incident?utm_source=tldrdevops)

Railway disclosed a security incident where an attacker accessed internal systems from October 20 to 22 to target AI provider API keys. Environment variables for approximately 100,000 workspaces, or 1.85% of the total, were potentially compromised. Railway revoked credentials with partner vendors and accelerated a rollout of single-tenant builder infrastructure.
