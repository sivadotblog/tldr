### News & Trends

[### Announcing the Workload Conformance Working Group (4 minute read)](https://kubernetes.io/blog/2026/10/27/announcing-workload-conformance-wg/?utm_source=tldrdevops)

The Kubernetes community launched a Workload Conformance Working Group to write a shared specification and tests for how workloads behave at runtime. The group aims for a stable first specification within two to three release cycles and seeks input from operators and application maintainers.

[### Match monitoring depth to workload needs with Infrastructure Basic (4 minute read)](https://www.datadoghq.com/blog/infrastructure-monitoring-basic/?utm_source=tldrdevops)

Datadog describes Infrastructure Basic, a lightweight tier that collects core host metrics and selected process status for lower-priority workloads. It uses the same Agent in basic mode and can run alongside Pro or Enterprise tiers in one organization.

[### Supabase Compute: run your agents inside your project (3 minute read)](https://supabase.com/blog/supabase-compute-private-alpha?utm_source=tldrdevops)

Supabase launched Supabase Compute in private alpha to run agents, background jobs, and APIs directly alongside user data. The offering currently supports the us-west-2 region. Dreambase reported query latency dropped from 65 ms in another region to a median of 2.9 ms after moving a data agent to the new platform.

### Opinions & Tutorials

[### One Hub, 34 Clusters: Lessons From a GitOps Control Plane at Scale (5 minute read)](https://cloudnativenow.com/contributed-content/one-hub-34-clusters-lessons-from-a-gitops-control-plane-at-scale/?utm_source=tldrdevops)

Nitish Mane describes an Argo CD hub that managed 34 clusters across 22 AWS accounts and one Oracle Cloud tenancy from a repository of 174 Helm charts. Per-cluster contracts, CI manifest diffs, and no-prune settings kept changes safe, and onboarding reportedly fell from 4 days to 1.7 hours.

[### How to Integrate Terraform with Backstage for Self-Service (17 minute read)](https://spacelift.io/blog/terraform-backstage?utm_source=tldrdevops)

Mattias Fjellström explains how to connect Terraform with Backstage through the software catalog, software templates that open pull requests, and the Spacelift plugin. Backstage collects requests but does not run Terraform, so version control remains the source of truth.

[### 1M Durable Workflows per Second on Postgres (6 minute read)](https://www.dbos.dev/blog/one-million-workflows?utm_source=tldrdevops)

DBOS scaled a benchmark of no-op durable workflows from 20,000 per second on one Postgres server to one million across 50 shards using PgDog. The main obstacle was a contention feedback loop that collapsed throughput when a shard slowed down. Advisory locks limited concurrent dequeuers and restored stable scaling.

[### Macro (GitHub Repo)](https://github.com/macro-inc/macro?utm_source=tldrdevops)

Macro is a unified workspace that combines email, chat, docs, tasks, agents, and CRM into a single interface with shared team memory. It links all objects, such as emails and tasks, via a bidirectional graph so AI agents and users can search across tools without switching contexts.

### Miscellaneous

[### The AI observability race will be won on interoperability (5 minute read)](https://thenewstack.io/ai-observability-through-interoperability/?utm_source=tldrdevops)

OpenTelemetry offers a common method to capture and describe AI behavior using shared conventions for conversations and messages. This standardization helps teams compare models, reduce duplicate integration work, and measure cost per outcome rather than just token counts.

[### The Pwn Request Reckoning: What Still Works Against GitHub Actions (9 minute read)](https://www.wiz.io/blog/github-actions-security-pwn-request-reckoning?utm_source=tldrdevops)

GitHub's upcoming platform changes in 2026 will make pull\_request\_target attacks harder, but gaps remain involving outdated checkout versions, script injection, and unprotected triggers like issue\_comment. Pinning actions to old SHA values predating the July 2026 backport release bypasses the new checkout protections entirely. The default policy also does not apply to private repositories or workflow\_run events.
