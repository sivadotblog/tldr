### News & Trends

[### SRE book second edition (3 minute read)](https://cloud.google.com/blog/products/devops-sre/sre-book-second-edition/?utm_source=tldrdevops)

Google has released a completely rewritten second edition of its Site Reliability Engineering book with O'Reilly Media. The update reflects a decade of changes to the reliability field, including the rise of AI, microservices, and platform engineering. The new text includes guidance on modern challenges like running large language models and using AI to enhance operational reliability.

[### Announcing AWS Lambda Web Functions (5 minute read)](https://aws.amazon.com/blogs/aws/announcing-aws-lambda-web-functions-for-fast-consistent-web-app-performance-anywhere/?utm_source=tldrdevops)

AWS Lambda Web Functions is a new form factor that runs standard HTTP web applications without rewriting code into an event handler. Developers can deploy existing Node.js servers built with frameworks like Express or Next.js, and the service automatically handles scaling and multi-region distribution. Each execution environment handles up to 128 concurrent requests, and billing is based on active CPU time rather than total duration. It is available today in five regions.

### Opinions & Tutorials

[### AKS Is Growing – Along With Its Kubernetes Utilization Problem (5 minute read)](https://cloudnativenow.com/features/aks-is-growing-along-with-its-kubernetes-utilization-problem/?utm_source=tldrdevops)

Per the 2026 State of Kubernetes Optimization Report, AKS CPU utilization fell to 8% and memory to 20%, with CPU overprovisioning at 69%. GPU utilization averages 5% overall and 2% on AKS, driven by conservative resource requests that are rarely revisited.

[### Under the hood, off the hot path: How D1 scales to millions of databases (24 minute read)](https://blog.cloudflare.com/d1-control-plane/?utm_source=tldrdevops)

Cloudflare scaled D1's control plane to manage millions of SQLite-backed databases while keeping centralized components out of the query hot path. Distributed routing metadata, pooled Postgres connections, precomputed aggregations, and idempotent background processes reduce bottlenecks as database counts grow.

[### Headless Observability: The Next Evolution of Autonomous Operations (6 minute read)](https://newrelic.com/blog/news/blogheadless-observability-autonomous-operations?utm_source=tldrdevops)

New Relic argues observability must evolve for AI agents as well as humans, since agents need trusted operational intelligence rather than raw telemetry. Its Ground Truth layer combines telemetry, relationships, evidence, and context, separating intelligence from presentation so dashboards and APIs serve both audiences.

### Miscellaneous

[### What gets TOASTed in Postgres (12 minute read)](https://planetscale.com/blog/what-gets-toasted-in-postgres?utm_source=tldrdevops)

Postgres TOAST compresses oversized variable-length values and moves them into separate storage when necessary. SQL examples show why LZ4's faster compression does not always produce smaller values or faster reads: pglz can outperform it for short previews, while uncompressed external storage can improve reads from the middle of large binary values.

[### Shipping Media Over QUIC at Meta Scale for Instagram Live Ingest (6 minute read)](https://engineering.fb.com/2026/10/12/video-engineering/shipping-media-over-quic-at-meta-scale-for-instagram-live-ingest/?utm_source=tldrdevops)

Instagram Live now uses the open standard Media over QUIC (MoQ) protocol for live video ingest on iOS and Android. This switch moves development from Meta's in-house RUSH protocol to a shared IETF standard developed with Google, Akamai, and others. Meta says the MoQ path matched RUSH on streaming quality and reliability measures during testing.
