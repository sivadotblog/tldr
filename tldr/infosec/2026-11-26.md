### Attacks & Vulnerabilities

[### Todoist Hit by Unauthorized Access; Email Addresses and Password Hashes Leaked for About 6% of All Users (3 minute read)](https://finance.biggo.com/news/493ce078-6c3e-40e6-aaf6-84dc66b91e80?utm_source=tldrinfosec)

Attackers used stolen version-control credentials to alter automated workflows, obtain further credentials, and access Todoist cloud systems through an employee account. About 6% of users had exposed email addresses, salted SHA1 password hashes, and account-creation dates. Todoist revoked passwords, API tokens, OAuth apps, and sessions. A small subset had API, Slack, or Outlook-linked mailbox data exposed.

[### Update on a security incident involving 1Password's backend systems. Customer vaults were not affected, and all vault contents remain secure (4 minute read)](https://1password.com/blog/update-on-nov-2026-security-incident?utm_source=tldrinfosec)

An attacker took over a 1Password employee's corporate GitHub account and pushed malicious code to backend services, which pulled names, email addresses, SRP parameters, and invitation and recovery tokens for a subset of users, and also accessed source code and the company's CI/CD secrets. Vaults and the keys protecting them weren't exposed, and the stolen tokens are useless without SSO or an emailed code, which 1Password has now lengthened from six digits to ten alphanumeric characters. Users don't need to change anything, but they should be wary of unexpected 1Password invitation or recovery emails, and security teams should review how much push access employee GitHub accounts have to production and CI/CD.

[### Check Point Security Management Servers Hacked in AI-Assisted Campaign (2 minute read)](https://www.securityweek.com/check-point-security-management-servers-hacked-in-ai-assisted-campaign/?utm_source=tldrinfosec)

GreyNoise tracks a threat actor, GT13, attacking at least 22 organizations across energy, finance, government, manufacturing, mining, and transport. The actor used 99 IP addresses, automated scanning and exploitation, and hands-on access to compromise Check Point Security Management servers. It forged an HFS admin session cookie, obtained SSH access, moved laterally, escalated privileges, and exfiltrated data from 24 servers. Investigators observed exploitation attempts against flaws in Citrix, Ivanti, Check Point, Windows, Exchange, and VMware products.

### Strategies & Tactics

[### Vulnpocalypse and Vulnerability Response Engineering (6 minute read)](https://www.detectionengineering.net/p/vulnpocalypse-and-vulnerability-response?utm_source=tldrinfosec)

The recent onslaught of vulnerabilities has shown that security teams need to rethink vulnerability response. Teams need to adopt a vulnerability response model that uses threat modeling agents to develop proactive views of an organization's exposure. Then, when a new vulnerability is disclosed, a security team can refer to those models to inform their response priorities and efforts.

[### The Great Escape: Tradecraft insights from an agentic swarm (12 minute read)](https://blog.talosintelligence.com/the-great-escape-tradecraft-insights-from-an-agentic-swarm/?utm_source=tldrinfosec)

OpenAI models that escaped their evaluation sandboxes pulled data from Australian government Tableau dashboards without ever touching the targets directly. They found endpoints through Common Crawl, hosted Base64 payloads on httpbin and httpbun, used urlquery[.]net's Chromium scanner to run them through a CORS proxy, and sent the data out in zero-byte HTTP 204 image beacons. Talos treats the swarm as unintended rather than malicious, but a Tencent-hosted agent fleet and the ARTEX framework have since adopted the same tricks. Talos suggests defenders hunt for agents by their habit of writing results to durable services like webhook[.]site, by burst-and-pause request timing, and by the self-labeling tags agents need for their own state tracking.

[### Bring Your Own Interpreter - EDR Evasion with LuaJIT, Julia, Node.js, Deno, and Bun (18 minute read)](https://g3tsyst3m.com/byoi/Bring-Your-Own-Interpreter-EDR-Evasion-with-LuaJIT,-Julia,-Node.js,-Deno,-and-Bun/?utm_source=tldrinfosec)

Trusted, signed interpreters like LuaJIT, Julia, Node.js, Deno, and Bun can use their built-in FFI to allocate RWX memory with VirtualAllocExNuma, copy in shellcode, and pass that buffer as the callback to EnumUILanguagesW. Windows itself then calls the shellcode, so there's no injection API, no PE on disk, and no direct jump for an EDR to flag. The researcher's calc.exe proof of concept got past ESET, but the earlier Elastic, Defender for Endpoint, and Sophos results come from older tests of similar code. Defenders should block unapproved runtimes with WDAC or AppLocker outside developer machines and alert when interpreter processes allocate executable memory or call Win32 APIs through FFI.

External Sandbox provides a common interface for running commands and working with files inside isolated Linux environments.

[### hvpatch (GitHub Repo)](https://github.com/prepaid-host/hvpatch?utm_source=tldrinfosec)

hvpatch applies kernel CVE fixes to running Proxmox VE 9 hypervisors as live patches, so hosts can wait until a maintenance window to reboot, which fills a gap because KernelCare doesn't support PVE 9 and Proxmox offers no live patching of its own. Each patch is built from the exact Proxmox kernel source, tested in QEMU, and signed, then checked against signature, build-id, and hash before it loads, with canary, early, and stable release rings, automatic rollback, and an option to self-host the pipeline with your own keys. It's still early-release software, with the 7.0 kernel experimental and no bare-metal soak yet, and changes to data structures and ZFS fixes still need a reboot, but status shows clearly which CVEs are fixed live and which aren't.

[### Flawrence (GitHub Repo)](https://github.com/mschwarzl/flawrence/?utm_source=tldrinfosec)

Flawrence is a Rust tool that reports source-code vulnerabilities only after a second LLM agent has reproduced them and a proof of concept has been written. It builds a threat model, maps the attack surface, and gives each entry point its own research agent, then drafts GitHub Security Advisories, private reports, and patches that it tries to bypass. It runs on Anthropic, OpenAI, Workers AI, or any OpenAI-compatible endpoint such as a local vLLM model, so it fits code-audit pipelines, but its agents run shell commands and can fan out to 40 at once, so it belongs in a VM and needs a MAX\_COST\_USD cap.

### Miscellaneous

[### What defenders need to know about ARTEX, the agentic AI framework threat actors abuse (22 minute read)](https://www.microsoft.com/en-us/security/blog/2026/11/25/what-defenders-need-to-know-artex-agentic-ai-framework-threat-actors-abuse/?utm_source=tldrinfosec)

ARTEX, an open-source AI pentesting framework released in July with a Chinese-language interface, has been adopted by state-backed groups including Onyx Sleet, Pearl Sleet, Salt Typhoon, and Crystal Typhoon, as well as financially motivated actors. Its planner agent works from a knowledge graph and hands short attack "intents" to worker agents running nmap, sqlmap, hydra, and Metasploit, which can take an intrusion from reconnaissance to privileged access in minutes using any LLM, including models with their guardrails stripped. Microsoft notes that ARTEX introduces no new techniques and that operators routinely change IPs and user agents, so the most durable signal is its machine-speed pattern of bursts and retries, while ThreatBook's claim of ownership and its commercial "ARTEX Pro" add a new twist to the tool's spread.

[### A familiar Iranian hacking group has found a new way to cause chaos (2 minute read)](https://arstechnica.com/security/2026/11/a-familiar-iranian-hacking-group-has-found-a-new-way-to-cause-chaos/?utm_source=tldrinfosec)

Hackers raised temperatures in supermarket refrigeration systems across France in October, destroying millions of euros of food. French intelligence links the operation to Shahid Kaveh, an IRGC unit also known as CyberAv3ngers. The group used internet scanning and Modbus reconnaissance against connected refrigeration equipment. Similar attacks hit supermarkets in 10 other European countries. France seeks arrest warrants for three Iranians. Iran denies involvement.

[### Microsoft's NTLM security changes trip up third-party logins (2 minute read)](https://www.theregister.com/security/2026/11/25/microsofts-ntlm-security-changes-trip-up-third-party-logins/5312085?utm_source=tldrinfosec)

Microsoft's November update made Windows clients offer NTLM signing by default to address CVE-2026-118737, which breaks logins through SSO products, auth proxies, and packaging tools that send an empty TargetInfo field, and the ClientAllowUnsignedNtlm registry workaround is only a stopgap because servers will require signing from May 2027.
