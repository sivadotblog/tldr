### Attacks & Vulnerabilities

[### Tech Firms Dismantle Botnet That Turned 1.3M TV Boxes Into Proxies (3 minute read)](https://krebsonsecurity.com/2026/11/tech-firms-dismantle-botnet-that-turned-1-3m-tv-boxes-into-proxies/?utm_source=tldrinfosec)

Google says it disrupted the XCPE botnet, built from more than 1.3 million Android TV boxes made by Videostrong. The devices secretly rented users' internet connections to residential-proxy services and ran ad fraud. Google took down the operator's domains and servers. The action may cut off more than 10 million additional infected devices. The malware also appeared in telehealth devices, karaoke machines, and digital signage.

[### Mercado Bitcoin Hit By $46M Security Breach (2 minute read)](https://www.theblock.co/news/defi/2026-11-02-mercado-bitcoin-hack-46-million-brazil-exchange-432333?utm_source=tldrinfosec)

Mercado Bitcoin, Brazil's largest crypto exchange, disclosed that it suffered a security incident involving approximately $46.3M in assets. Mercado stated that the breach did not affect customers or result in a data breach. It has temporarily paused transactions while it investigates the breach further, and has published the destination wallet address.

[### Financial Services Firm MoneySmart Hit By IT Security Breach, Some Customers' Data Copied (2 minute read)](https://www.channelnewsasia.com/singapore/moneysmart-data-breach-security-incident-6515356?utm_source=tldrinfosec)

Financial services company MoneySmart disclosed that a “security incident” led to the disclosure of some of its customers' personal data in Hong Kong and Singapore. MoneySmart said the data may include names and email addresses, shipping addresses, and application or policy reference numbers for customers who submitted rewards claims.

### Strategies & Tactics

[### Prioritize What Attackers Will Exploit: 4 Elements of Strong Exposure Prioritization (7 minute read)](https://www.gartner.com/doc/reprints?id=00ThR00000Mow90UAB&amp;ct=261014&amp;st=sb&amp;submissionGuid=1eef772c-10d7-49e0-b187-de975a5cc321&amp;utm_source=tldrinfosec)

Fewer than 10% of vulnerabilities are exploited, but remediation programs often treat most findings as urgent. Rank exposures using active-exploitation intelligence, asset criticality, EPSS-style exploitability modeling, and control validation. A vulnerability on an internet-facing system that handles regulated data, has known exploitation, and lacks segmentation should outrank a high-CVSS finding on an isolated internal asset. The model measures success by fewer exploitable exposures and reduced remediation effort, rather than ticket volume.

[### The Quiet Phase: Why Active Directory Group Enumeration Deserves Your Attention (9 minute read)](https://trustedsec.com/blog/the-quiet-phase-active-directory-group-enumeration?utm_source=tldrinfosec)

Attackers map who sits in Domain Admins with SharpHound or PowerView long before they change any group membership, and an audit entry (SACL) on the group's member attribute turns those reads into Event 4662, or 4799 for built-in groups, on the domain controller that answered. On real privileged groups, the signal drowns in reads from directory sync, Exchange, and admin tooling, and SAMR-based tools like net group /domain bypass it entirely. Pair the audit with decoy groups that nothing legitimate ever reads, correlate a decoy read and a real admin-group read from the same logon session, and check coverage with its QuietPhase PowerShell script.

[### Jailbreaking my car's navigation system just so I can change the time (11 minute read)](https://blog.nns.ee/2026/11/02/renault-hack/?utm_source=tldrinfosec)

A Renault Latitude's TomTom Carminat LIVE head unit hid its clock settings behind a legitimate navigation SD card. The card used CID-based DRM and signed files, so a blank card could not supply the missing menu definition. The author reverse-engineered the Linux 2.6.28 firmware, built a QEMU and CAN emulator, and found that master.script allowed a root path-traversal write through its LOG command and wrote |/bin/sh /media/sdcard/payload.sh into /proc/sys/kernel/core\_pattern, then crashed /bin/dbus-monitor to trigger a coredump and execute the payload as root. The exploit enabled an eMMC backup and a timezone patch from UTC+3 to UTC+2.

[### dragon-tales (GitHub Repo)](https://github.com/Fare9/dragon-tales?utm_source=tldrinfosec)

dragon-tales is a binary analysis library for disassembling, assembling, and analyzing machine code across multiple architectures.

[### Crashtest (GitHub Repo)](https://github.com/dhaupin/crashtest?utm_source=tldrinfosec)

Crashtest runs adversarial security tests against a JavaScript app's real route handlers entirely in-process, so it never opens a socket or needs a live server. Its built-in campaigns cover identity-spoofing headers, prototype pollution, cross-tenant ID enumeration, leaked secrets, and cost-amplification abuse, and every attack ends in a verdict of REFUSED, EXPLOITED, or BOUNDED (an accepted risk with a named owner). It plugs into Hono, Express, and Fastify, and its GitHub Action fails CI only on a new exploit or a regression, never on risks the team already accepted.

[### safeagents (GitHub Repo)](https://github.com/huggingface/safeagents?utm_source=tldrinfosec)

safeagents is a local proxy that sits between a coding agent and its model API and checks each tool call before the harness runs it. It blocks calls to undeclared tools and calls that reach hosts nobody mentioned in the conversation, and it runs atif-scan detectors that catch reads of /proc/1/environ or curl --noproxy. Ambiguous calls can go to an optional judge model that sees only the user's prompt, the call, and the findings, never the agent's reasoning, and it works with any harness that accepts a custom base URL, including Claude Code, OpenCode, and Hermes.

[### How Cisco defends at machine speed with OpenAI (3 minute read)](https://openai.com/index/cisco-cyber/?utm_source=tldrinfosec)

Cisco is pairing its network telemetry with OpenAI's Daybreak program and GPT-6 Astra to link signals that look harmless on their own and to speed up vulnerability patching, and Cisco's Jeetu Patel calls the gains "step function improvements." [### Token thieves costing companies $100K+ per day in illicit LLM charges (3 minute read)](https://www.theregister.com/security/2026/11/02/token-thieves-costing-companies-100k-per-day-in-illicit-llm-charges/5306967?utm_source=tldrinfosec)

Google Mandiant reports that criminals are stealing LLM API keys and cloud service account credentials, then running high-volume model inference at victims' expense. Charges reached $100,000 per day in one case and $1 million in total before access was revoked. One service, Jet Night, allegedly used stolen keys to offer access to frontier models for about $60 per month.

[### Red Hat Patches 9.8-Rated Linux TCP RCE Flaw While Ubuntu Releases Fixes for Testing (4 minute read)](https://thehackernews.com/2026/11/red-hat-patches-98-rated-linux-tcp-rce.html?utm_source=tldrinfosec)

Red Hat has patched CVE-2026-98432, a 9.8-rated use-after-free in the Linux kernel's IPv4 TCP handling. A remote attacker can send IPv4 Record Route or Timestamp options to a listening TCP port and trigger a race that reads freed memory, potentially allowing code execution. RHEL 8, 9, and 10 fixes require a reboot. No exploitation has been reported. An nftables rule can drop IPv4 TCP packets with IP options, but it does not fully prevent exploitation.
