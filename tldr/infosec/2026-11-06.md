### Attacks & Vulnerabilities

[### Hackers exploited iOS and Android flaws to infect phones (3 minute read)](https://arstechnica.com/security/2026/11/hackers-exploited-ios-and-android-flaws-to-infect-phones/?utm_source=tldrinfosec)

Attackers likely linked to Russia's Foreign Intelligence Service used watering holes, proxy domains, and a compromised Ukrainian analytics service to inject JavaScript into mobile traffic. The code profiled visitors and delivered zero-click exploit chains against outdated iOS or Android devices, including DarkSword. Payloads sought browser cookies, Wi-Fi passwords, and full device data. Targets included sites connected to US and UK diplomatic circles and Ukraine.

[### Chainalysis Warns All Users Hit In Cyber Breach Involving “Agentic” Techniques (2 minute read)](https://therecord.media/chainalysis-all-users-hit-by-agentic-cyberattack?utm_source=tldrinfosec)

Blockchain analytics company Chainalysis released a warning that all of its users' data may have been compromised following an attack by a threat actor utilizing “offensive agentic techniques.” The stolen data includes names, usernames, password hashes, and live tokens for all Chainalysis users. Chainalysis also temporarily took some other services offline, including its Know Your Transaction (KYT) cryptocurrency transaction monitoring service.

[### Anthropic won't fix a Claude Dispatch flaw that could let attackers execute remote commands across corporate boundaries (5 minute read)](https://www.theregister.com/research/2026/11/05/anthropic-wont-fix-a-claude-dispatch-flaw-that-could-let-attackers-execute-remote-commands-across-corporate-boundaries/5307684?utm_source=tldrinfosec)

A browser extension with access to claude.ai can use Claude Dispatch to send prompts to Claude Desktop and achieve remote code execution. The attack exploits shared web and desktop sessions, repeated approval clicks, and a malicious npm package. It can also reach a work computer from a personal browser session. Anthropic knew of the issue in May but has not issued a fix. Dispatch remains available to existing users.

### Strategies & Tactics

[### GhostMap: The Android flaw that crashes your phone before you open the app (17 minute read)](https://www.bitdefender.com/en-us/blog/labs/ghostmap-android?utm_source=tldrinfosec)

An APK entry using a nonstandard compression method slips past libziparchive's size check, while libandroidfw memory-maps it at its full declared size. As a result, any process that reads a malformed resource receives a SIGBUS. That flaw lets an app with no code or permissions trap system\_server in a boot loop that only a factory reset clears, or cause its own icon to crash on every uninstall screen. Bitdefender found it when a packed banking dropper in the wild crashed its emulators, but the persistent boot loop was its own escalation. Google declined to ship a security fix even though the bug reproduces on Android 10 through 17. With no patch coming, defenders should flag APKs whose ZIP entries use compression methods other than stored or deflate before they're installed, since an on-device warning may come too late.

[### Escaping Firecracker from Guest Userspace (9 minute read)](https://www.coinspect.com/blog/firecracker-escape/?utm_source=tldrinfosec)

Coinspect demonstrated a Firecracker sandbox escape from guest userspace. CVE-2026-122192 allowed a guest to read and modify live Firecracker VMM memory and gain code execution in the host-side process. The flaw stemmed from a failed memory replacement after a snapshot-backed RAM discard, leaving a stale KVM memory slot pointing to reused VMM memory. A second issue, FC-03, allowed VMM code to use io\_uring to perform host operations blocked by seccomp, including sending a network message to a host listener. Firecracker v0.23.0 through v1.16.1 are affected. v1.16.2 and v1.17.0 fix the escape.

[### The SOC Files 5: Ghost in the pipeline, or a fileless SharePoint breach by Storm-2603 (15 minute read)](https://securelist.com/storm-2603-fileless-toolshell-attack/121467/?utm_source=tldrinfosec)

Storm-2603 used the ONYPHE scanner to check a SharePoint server for ToolShell (CVE-2025-53770), waited three days, and on Christmas Eve loaded a webshell directly into IIS's w3wp.exe process memory. The webshell activated only for a specific User-Agent, tunneled into the internal network with suo5, escalated to SYSTEM using EfsPotato, and then moved to a vulnerable Velociraptor build, an EDR-killer driver, and a blocked Warlock ransomware attempt. Kaspersky attributed the intrusion with moderate confidence. Defenders should hunt for IIS paths that resolve in config but have no file on disk, which appear as IIS-Configuration ETW events 25 and 47 without the usual file-change monitoring events. Kaspersky has released CLRDeserializationExploitFinder to flag the deserialization exploit itself.

[### synology-nas-cli (GitHub Repo)](https://github.com/akari-sora/synology-nas-cli?utm_source=tldrinfosec)

synology-nas-cli checks a Synology NAS for the exposures exploited in October's C3RB3R/.L0CK3D ransomware campaign: unpatched DSM builds, vulnerable SA-26:14 packages, QuickConnect and UPnP port forwarding, SMB1, ransom notes, and CVE-2024-10441 exploit traces. It shows each fix as a before-and-after dry-run plan, applies it, and reads every setting back to confirm. If encryption is already running, it can freeze the encryptor with SIGSTOP and capture its memory to recover keys. It's a zero-dependency Python CLI with an MCP server, so a Claude Code or Codex agent can run the audit end to end.

[### Sectiv (GitHub Repo)](https://github.com/zack0x01/burp-sectivai?utm_source=tldrinfosec)

Sectiv is a Burp Suite extension that runs captured proxy traffic past an LLM, guided by editable "skills" for IDOR, XSS, SQLi, and SSRF, and returns triaged findings with CVSS scores and HTML, Python, or curl PoCs. Testers can load two accounts to help the model reason about broken access control. It masks cookies, tokens, and JWTs before sending traffic to providers like OpenAI, Claude, DeepSeek, or a local Ollama model. Skills can be imported, exported, and tailored per target, and findings export to HTML, Markdown, or JSON for reporting.

[### GPT-6 Cyber: Advancing the frontier of aligned cybersecurity agents (10 minute read)](https://openai.com/index/introducing-gpt-6-cyber/?utm_source=tldrinfosec)

OpenAI's GPT-6 Cyber built working exploits for 948 Linux kernel vulnerabilities, more than five times GPT-5.6 Sol's count with the same harness, and found 81 previously unknown high-severity Firefox bugs. OpenAI also trained it to stay within the scope a researcher sets: on a honeypot evaluation, it avoided easy-to-exploit, out-of-scope services in 99.93% of runs without a safety prompt and 100% with one, enough for OpenAI to rate it Critical for cybersecurity under its Preparedness Framework. Approved defenders reach it through Daybreak Red, which requires IP allowlisting by default and runs misuse monitoring, and a new tier gives critical infrastructure teams authorized OT/ICS testing.

### Miscellaneous

[### Apple Will Scan Shared iCloud Links for Harmful Content, but Won't Explain What Counts as Harmful (3 minute read)](https://www.techtimes.co.uk/apple-scan-public-icloud-links-1809720?utm_source=tldrinfosec)

Apple will check photos and files shared via iCloud's “Anyone with the Link” setting for harmful content on iOS, iPadOS, and macOS 27.3. Publicly shared items lose end-to-end encryption, even with Advanced Data Protection enabled. Apple can remove files, block accounts, prevent re-registration, and contact law enforcement. It has not defined “harmful,” explained the screening method, said whether people review flags, or confirmed whether existing public links are covered.

[### OpenAI AI Pipeline Generates 948 Linux Root Escalation Exploits in 30-Hour Run (3 minute read)](https://thehackernews.com/2026/11/openai-ai-pipeline-generates-948-linux.html?utm_source=tldrinfosec)

OpenAI says an automated pipeline reproduced 1,724 Linux kernel vulnerabilities in 30 hours and generated 948 working local privilege-escalation exploits. The run produced 291 information-leak proofs of concept, patches for identified flaws, and at least 10 novel exploitation techniques. It cost $1.21 million in API credits, or $1,279 per exploit. OpenAI says unpatched systems with low-privileged access should be treated as accessible to well-resourced attackers with root access.

[### Bank Phishing Sites Show Fake ‘Suspended' Pages to Evade Takedowns (3 minute read)](https://www.securityweek.com/bank-phishing-sites-show-fake-suspended-pages-to-evade-takedowns/?utm_source=tldrinfosec)

Kela found more than 300 fake bank domains using a phishing kit that records visitor IP addresses. First visits receive bank login pages. Repeat visits receive a fake hosting "suspended" notice. This can make takedown teams classify live sites as inactive. The campaign targets business banking and treasury logins at 189 US institutions, with activity also seen in the UK, Australia, and New Zealand.
