### Attacks & Vulnerabilities

[### A Peripheral Path to SYSTEM - Exploiting Logi Options+ for SYSTEM Shells (7 minute read)](https://blog.amberwolf.com/blog/2026/september/a-peripheral-path-to-system---exploiting-logi-options+-for-system-shells/?utm_source=tldrinfosec)

Logi Options+, Logitech's widely used app for configuring its mice and keyboards, allowed any standard Windows user to reach SYSTEM because its privileged updater trusted only pipe connections from an agent process the user could inject. Researchers at AmberWolf used that access to override the {depot} path via the reinstall IPC endpoint, which directed a SYSTEM msiexec call to an unsigned MSI that skipped signature checks because the manifest set isSystem to true. The bug is tracked as CVE-2026-12518 and was patched on August 19, so admins should confirm that fleets run a newer build and alert on msiexec spawned by logioptionsplus\_updater.exe from user-writable paths.

[### Mass-Scanning Campaign Exploits Vite Flaw to Extract Cloud Credentials From Exposed Dev Servers (2 minute read)](https://thehackernews.com/2026/09/mass-scanning-campaign-exploits-vite.html?utm_source=tldrinfosec)

Attackers scanned exposed Vite development servers in August and exploited CVE-2026-39364. Crafted query parameters bypassed server.fs.deny and returned protected files through /@fs/. Observed targets included .env files, AWS credentials, Azure profiles, Terraform state, database passwords, and /proc data with requests spoofing crawler user agents and forged forwarding headers.

[### ClickFix attacks are tricking Mac and Windows users into hacking themselves (2 minute read)](https://techcrunch.com/2026/09/14/clickfix-attacks-are-tricking-mac-and-windows-users-into-hacking-themselves/?utm_source=tldrinfosec)

Attackers hijacked HBO Max's Reddit advertising account and posted malicious ads. The ads led to fake HBO Max pages with CAPTCHA-style ClickFix prompts that made the victims copy commands into Windows Command Prompt, PowerShell, or macOS Terminal. The commands installed infostealers that targeted passwords, active sessions, and crypto wallets. Reddit paused the ads three days after a user flagged them, though how the account was taken over remains unknown.

### Strategies & Tactics

[### Beltdown2: Escaping the Cursor CLI sandbox (7 minute read)](https://www.accomplish.ai/blog/beltdown2-escaping-the-cursor-cli-sandbox/?utm_source=tldrinfosec)

A malicious workspace can place a core.fsmonitor hook in .git/config. Cursor CLI ran internal Git commands outside its macOS Seatbelt sandbox. A read-only prompt triggered git ls-files, which executed the hook. The proof payload wrote to $HOME, while sandboxed shell commands could not. Anysphere acknowledged the report and shipped Cursor CLI 2026.08.04-aaa8809, and the fix injects GIT\_CONFIG environment settings into every Git spawn, disabling core.fsmonitor, custom hooks, and repository attributes.

[### FulcrumSec - A look at their tradecraft (8 minute read)](https://www.aitmfeed.com/blog/blog-1/fulcrumsec-a-look-at-their-tradecraft-20?utm_source=tldrinfosec)

FulcrumSec, a financially motivated data extortion gang behind breaches at Manchester Airports Group, Arup, and Novo Nordisk, told Lab539 it runs up to 250 servers scanning client-side JavaScript and fresh bugs like React2Shell, then bulk-tests harvested credentials before picking victims. From there, it chains pivots through GitHub repos, AWS, Azure, and Secrets Manager without touching an endpoint, with a single Arup PAT reportedly opening about 10,000 private repositories. Defenders should baseline normal identity behavior and flag tokens that suddenly clone thousands of repos or enumerate unrelated secrets from unfamiliar infrastructure, since this activity relies on valid credentials rather than malware.

[### Unmasking Cloud Identities: From Behavioral Clustering to Automated Detection (11 minute read)](https://unit42.paloaltonetworks.com/behavioral-clustering-map-to-cloud-identities/?utm_source=tldrinfosec)

Unit 42 clustered the CloudTrail activity of over 40,000 identities across 125 AWS environments and found they fall into consistent functional roles like console admins, CI/CD runners, backup agents, and security tools, regardless of naming or assigned IAM policies. That behavioral baseline matters because attackers masquerade behind benign labels and existing permission profiles, so a backup service suddenly running admin actions stands out even when its permissions allow it. The approach distills into a lightweight classifier that runs as standard SQL, letting teams tag identity roles at scale without a full ML pipeline.

### Miscellaneous

[### Two DGX Sparks, 33 Local Models, One Question: Can Local AI Actually Red Team? (38 minute read)](https://betheadversary.com/posts/dgx_spark_red_team_bench/?utm_source=tldrinfosec)

Roei Sherman evaluated 33 local models on a two-node DGX Spark cluster for red teaming capabilities. The evaluation consisted of a security capability that tested whether the models can reason by testing them with a three-phase red team scenario, a red team benchmark to test the willingness and accuracy of model responses, and a coding benchmark consisting of Aider Polyglot plus two custom suites. Sherman found that MoE models consistently performed above their model class across all three benchmarks, with Qwen3.6-35B-A3B (FP8) winning the security capability benchmark, Qwen3-Coder-Next (FP8) winning the coding benchmark, and more mixed results on the red team benchmark.

[### Mythic C2 Activity at Internet Scale (5 minute read)](https://censys.com/blog/mythic-c2?utm_source=tldrinfosec)

Mythic, an open-source C2 framework that lets operators mix agents, transport profiles, and a shared web UI, is popular with red teams but has also turned up in real intrusions, according to new Censys research. Censys tracked 131 internet-exposed Mythic hosts, and 115 of them still carried the default O="Mythic" or O="Mythic C2" certificate. One cluster Censys flagged paired Mythic with custom Rust implants, Discord-based C2, and a domain disguised as Windows telemetry traffic.
