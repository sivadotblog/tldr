### Attacks & Vulnerabilities

[### Quest Diagnostics Data Breach Exposed ‘Certain Patient Records' (2 minute read)](https://www.securityweek.com/quest-diagnostics-reports-cyber-breach-affecting-certain-patient-records/?utm_source=tldrinfosec)

Quest Diagnostics reported unauthorized access to Quanum Lab Services Manager, a platform clients use to order tests and retrieve results, after discovering the intrusion on October 21st, notifying federal law enforcement, and engaging outside security specialists. The company believes certain patient records were accessed but has not identified the number of patients or the exact data exposed.

[### Researchers Push Over 2 Million Updates to Remotely Disable Popcorn Time Updater That Could Fuel a Botnet (4 minute read)](https://thehackernews.com/2026/10/researchers-push-over-2-million-updates.html?utm_source=tldrinfosec)

Eye Security pushed more than 2 million updates to disable an abandoned Time4Popcorn updater that installed code with SYSTEM or root privileges over unencrypted connections. The flaw, CVE-2026-30612, affected Windows, Mac, and Android builds. The updates cut related traffic by about 98 percent, and Eye then transferred 15 domains to Shadowserver. Users should uninstall Popcorn Time. Turning off the updater leaves the insecure application installed.

[### PHP-ocalypse: How two critical web bugs almost broke the internet (5 minute read)](https://techcrunch.com/2026/10/24/php-ocalypse-how-two-critical-web-bugs-almost-broke-the-internet/?utm_source=tldrinfosec)

Two PHP flaws, CVE-2026-109618 and CVE-2026-109619, enable unauthenticated remote code execution on unpatched servers. The PHP Foundation released fixes on October 21, and banks, retailers, hospitals, and government services briefly took systems offline to install them. Amazon detected exploitation about a week before disclosure, and Palo Alto Networks and Trail of Bits later confirmed compromises. Cloudflare reported a sharp rise in exploitation attempts after disclosure. PHP powers roughly 70% of web-facing sites, including WordPress, Drupal, Joomla, and MediaWiki.

### Strategies & Tactics

[### Field Notes: Reconstructing an Attacker's Workflow (6 minute read)](https://dfir.ch/posts/field_note_attacker_workflow/?utm_source=tldrinfosec)

PowerShell scripts recovered from an intrusion revealed a %TEMP% file-watching loop that fed commands to Invoke-Expression, overlapping tradecraft from Microsoft's TerminalFix ClickFix analysis. A fake Windows Security prompt looped until the victim entered valid credentials for a targeted account, logging every attempt in cleartext. At the same time, follow-on scripts enumerated AD computers, tested remote WMI access, and mapped readable SMB shares. Defenders should enable Script Block Logging (Event ID 4104) and hunt for string combinations like PromptForCredential, GetNetworkCredential().Password, and DirectorySearcher alongside PowerShell fanning out over TCP/445 or WMI.

[### Breaking the AWS MCP Python Sandbox (11 minute read)](https://xplo1t-sec.github.io/posts/breaking-the-aws-mcp-python-sandbox/?utm_source=tldrinfosec)

A researcher bypassed the Python sandbox in AWS' managed MCP Server aws\_\_\_run\_script tool. The sandbox used an AST validator and restricted runtime builtins, but it missed implicit attribute reads in Python match/case class patterns. By changing \_\_match\_args\_\_, the researcher read blocked attributes, recovered copyreg.\_\_newobj\_\_, accessed its \_\_globals\_\_, and reached the original \_\_import\_\_. This enabled subprocess imports and command execution in the Lambda container. The researcher obtained the Lambda role's credentials and read the sandbox source, but the credentials allowed only sts:GetCallerIdentity. AWS fixed the issue after HackerOne disclosed it.

### Miscellaneous

[### Autonomous attack agent in 'Skynet mode' hijacks other models to carry out its evil deeds (3 minute read)](https://www.theregister.com/security/2026/10/24/autonomous-attack-agent-in-skynet-mode-hijacks-other-models-to-carry-out-its-evil-deeds/5305215?utm_source=tldrinfosec)

Symantec captured an AI attack agent built to find unauthenticated or stolen-key OpenAI-compatible endpoints, then use hijacked models to plan attacks. Its “Skynet mode” allowed up to 100,000 unattended steps and included 74 tools for scanning, exploitation, credential theft, database dumping, remote code execution, and crypto-mining. Researchers found no proof it was used in real attacks, but the kit ran against a live target.

[### n0n Cyber Extortion Incident Involving 38 Maritime Companies Likely Traces Back to a Single Vendor (9 minute read)](https://cydome.io/n0n-cyber-extortion-incident-involving-38-maritime-companies-likely-traces-back-to-a-single-vendor/?utm_source=tldrinfosec)

The n0n extortion group listed 38 maritime organizations across 18 countries on its leak site, demanding roughly $1.22 billion combined, including $400 million from Ocean Network Express. Cydome's interim and unconfirmed analysis linked the batch to a single support archive tied to Korean maritime software vendor CyberLogitec, since at least 21 victims were documented customers and sample files referenced its OPUS and ALLEGRO products. The samples pointed to credentials, EDI traffic, and system documentation dating back to 2009, though one sample reused across two listings suggested that being named did not always mean an organization's own data was taken.

[### Indian government sites are serving revoked eMudhra certificates (4 minute read)](https://captnemo.in/blog/2026/10/23/emsign-revoked-gov-in/?utm_source=tldrinfosec)

Over 800 Indian government domains, including UIDAI and the Controller of Certifying Authorities that regulates eMudhra, were still serving certificates days after eMudhra revoked 9,356 of them on its unaffected emSign G1 RSA hierarchy. The mass revocation followed the discovery of trivially recoverable private keys in eight intermediates under emSign ECC Root CA G3, flaws that went unnoticed for 18 months and contradicted MeitY's claim of a limited, brief impact. Firefox's CRLite blocks the affected sites, but Chrome's CRLSet omits these revocations entirely, so Chrome, Edge, Android, and Safari on iOS load most of them without complaint.
