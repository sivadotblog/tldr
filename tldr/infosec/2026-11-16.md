### Attacks & Vulnerabilities

[### TSMC Employee Data Breach Linked to Cloud Provider (2 minute read)](https://www.bleepingcomputer.com/news/security/tsmc-employee-data-breach-linked-to-cloud-provider/?utm_source=tldrinfosec)

Taiwan Semiconductor Manufacturing Company (TSMC) confirmed that personal employee data had been leaked online after a threat actor put 6.9GB of data up for auction. TSMC stated that the data was stolen from the systems of a cloud service provider, but their systems were not breached. The threat actor claims that the data includes employees' national ID numbers, addresses, contact details, and banking information.

[### AntiFox AI Pentesting Platform Linked to Attacks That Accessed AWS Production Secrets (4 minute read)](https://thehackernews.com/2026/11/antifox-ai-pentesting-platform-linked.html?utm_source=tldrinfosec)

Arctic Wolf linked AntiFox, an open-source autonomous pentesting platform, to intrusions that deployed ASPX web shells through compromised IIS applications. Attackers extracted configuration data, database credentials, and AWS credentials, then used valid IAM identities to enumerate AWS services. Some activity reached production Secrets Manager values and S3 objects. AWS said its services were not compromised. It recommends least privilege, IMDSv2, removing long-term keys from application configurations, and GuardDuty.

[### Windows 0-Day Dropped by Disgruntled Researcher Hands Hackers System Rights (3 minute read)](https://arstechnica.com/security/2026/11/windows-0-day-dropped-by-disgruntled-researcher-hands-hackers-system-rights/?utm_source=tldrinfosec)

Nightmare Eclipse disclosed SignDrop, a Windows zero-day that lets a standard user gain System rights. It abuses the Common Log File System (CLFS), Windows Defender, symbolic links, and file permissions in an attack where Defender opens a user-created CLFS container, then CLFS creates a missing authentication file with Defender's System privileges. The researcher says the technique can bypass antivirus tamper protection, and it reportedly works on Windows 11 26H2 and Windows Server 2025 Experimental when CLFS authentication mode is 0 or 1.

### Strategies & Tactics

[### How 1Password for Agents Preserves Security and Privacy (5 minute read)](https://1password.com/blog/1password-for-agents-security-privacy?utm_source=tldrinfosec)

1Password for Agents lets AI agents sign in to accounts without ever seeing the password. When an agent asks for a login, the user gets an approval prompt, and the browser extension fills the credential only on the matching page and clears it if submission fails. The design rests on keys that 1Password stores but cannot decrypt.

[### The Binance Heist, Part One: Fifty Valid Signatures, One That Landed, and an Authority That Stood for 3 Hours 49 Minutes (38 minute read)](https://hwtn.io/essays/t0401-binance-part-one?utm_source=tldrinfosec)

On October 29, an attacker sent a single Ethereum transaction to Binance's "Binance 14" hot wallet carrying 50 EIP-7702 authorizations, all validly signed by the wallet's key. The one matching the wallet's current nonce took effect, so the wallet ran the attacker's sweeper contract as its own code for 3 hours 49 minutes and was drained seven times while automated top-ups kept refilling it. Binance's withdrawal suspension could not touch the delegation, which acted on-chain outside its withdrawal systems, and how the attacker reached Binance's internal signing service has not been explained beyond Binance's own account, so custody teams should monitor hot wallets for code appearing and keep a pre-built EIP-7702 revocation procedure ready.

[### Cyber Chaos Monkey: Staying Ahead of Security Threats With AI Agents (7 minute read)](https://shopify.engineering/cyber-chaos-monkey?utm_source=tldrinfosec)

Shopify's Cyber Chaos Monkey is an agentic vulnerability hunter that attacks its live production systems using test credentials, source code, and past bug reports. It sends probes, reads the production logs, and checks the results against source code to refine each exploit. Shopify said tens of thousands of runs have turned up dozens of serious findings without an outage. Containment relies on read-only ephemeral credentials, a credential-swapping proxy, an egress allowlist, plus a separate "judge" agent running a different model that watches the attacker agent live and ends the run if it breaks the rules of engagement or stops responding.

### Miscellaneous

[### Policy and Disclosure: 2026 Edition (6 minute read)](https://projectzero.google/2026/11/disclosure-policy.html?utm_source=tldrinfosec)

Google Project Zero has dropped its "90 + 30" disclosure policy for a "Full X" model. Bugs are now disclosed a fixed number of days after they are reported, whether or not they have been fixed. The window starts at 90 days, moves to 60 on February 2, 2027, and to 30 on January 3, 2028, and grace periods and variant rules are gone. The team said LLMs have made exploits from patches almost instantaneous, which makes post-patch soak time pointless, and have raised its bug volume to several per week in targets that used to yield a few a year.

[### Post-Quantum Authentication: Lessons from Prague (11 minute read)](https://www.ietf.org/blog/iab-pq-workshop-impressions/?utm_source=tldrinfosec)

At an October IAB workshop in Prague, users deploying post-quantum authentication reported no security problems with ML-DSA or SLH-DSA, but said signature size kept breaking old limits. An ML-DSA-65 signature is 3,309 bytes compared with 64 for Ed25519, which pushes handshakes past congestion windows, signed requests past URL limits, and firmware past device memory. The co-chairs argued that a migration is not finished until verifiers stop accepting classical roots, something Cisco expects some router certificates will not do until around 2035, and they also flagged AI coding agents as a new source of divergence because agents hand-roll incompatible crypto formats instead of calling libraries.

[### Italy Fines Meta $887M for Accessing Android Users' Photos and Videos (2 minute read)](https://www.theguardian.com/technology/2026/nov/15/italy-fines-meta-887m-for-accessing-android-users-photos-and-videos?utm_source=tldrinfosec)

Italy's data protection authority fined Meta €805m ($887m) after finding Facebook accessed Android users' photos, videos, and metadata without specific consent. The issue concerned the gallery-suggestions feature, which used a single app-wide authorisation. The regulator ordered Meta to seek separate, clearly explained consent and provide a way to disable the feature, as about 20 million Italian Android users were affected.
