### Attacks & Vulnerabilities

[### Google Patches Eighth Chrome Zero-Day Exploited in Attacks This Year (2 minute read)](https://www.bleepingcomputer.com/news/security/google-patches-eighth-chrome-zero-day-exploited-in-attacks-this-year/?utm_source=tldrinfosec)

Google has released an emergency security update to patch a new Chrome vulnerability that attackers are actively exploiting. The vulnerability stems from a use-after-free bug in the browser's XML parser and can be exploited by attackers to execute arbitrary code.

[### N-able Takes N-central Cloud Offline After Researcher Discloses 33 Zero-Days with PoC Exploits (2 minute read)](https://thehackernews.com/2026/11/n-able-takes-hosted-n-central-offline.html?utm_source=tldrinfosec)

N-able took hosted N-central environments offline and told on-premises customers to shut down servers after Sean Bales disclosed 33 zero-days, called Able2Shell, with proof-of-concept exploits. The flaws include credential theft, file writes, XXE, XSS, and root-level remote code execution. N-able says it found no active exploitation, but watchTowr observed exploitation attempts against honeypots.

[### Hackers Now Exploit Critical Barracuda ESG Flaws to Gain Root Access (2 minute read)](https://www.bleepingcomputer.com/news/security/hackers-exploit-barracuda-email-security-gateway-flaws-to-get-root-access/?utm_source=tldrinfosec)

Barracuda Networks reported that two vulnerabilities in its Email Security Gateway (ESG) appliance, patched last week, are being actively exploited. The first vulnerability stems from an authentication weakness that could be exploited to modify an appliance's global config, and the second lets unauthenticated attackers inject OS commands that are run as root. Barracuda said the vulnerabilities require access to the administrative console to exploit and urges organizations not to expose it to the public internet.

### Strategies & Tactics

[### PwC's CISO on AI, Robots & What's Next for Security (10 minute read)](https://www.darkreading.com/cybersecurity-operations/pwc-ciso-ai-robots-security?utm_source=tldrinfosec)

PwC global CISO and CIO James Shira says AI expands attack surfaces and accelerates change in patching, vulnerability management, and client requests. He expects organizations to reduce their digital footprint and use AI to replace some application front doors, potentially reducing exposure, although he also expects token costs to affect security budgets. Shira advises cybersecurity entrants to pursue certifications and hands-on experience. He recommends a four-year degree for executive roles and says boards respond to delivered results, clear explanations, and stories rather than technical jargon.

[### Trusted by Default: Qubole Cross-Account Access Abused in the Wild (8 minute read)](https://www.wiz.io/blog/qubole-cross-account-access-abused-in-the-wild?utm_source=tldrinfosec)

A threat actor used IAM credentials from Qubole's AWS account between October 14 and October 26. It assumed customer-created integration roles, enumerated AWS resources, read Lambda environment variables, Secrets Manager values, and SSM parameters, and then used TruffleHog to validate AWS, Entra ID, and Okta credentials. It downloaded S3 objects from buckets accessible through the assumed roles. Wiz also identified a separate actor using customer-owned AWS keys tied to Qubole integrations.

[### Exchange for breakfast: Turla's Cereal tricks are not for kids (12 minute read)](https://www.welivesecurity.com/en/eset-research/exchange-for-breakfast-turlas-cereal-tricks-are-not-for-kids/?utm_source=tldrinfosec)

Turla's newly discovered Cereal toolset turns a victim's Exchange server into its command-and-control system. A passive backdoor waits for encrypted commands sent through ordinary-looking OWA, Autodiscover, and ActiveSync paths. Meanwhile, a module injected into EdgeTransport.exe hooks existing transport agents to quietly copy emails and attachments involving NATO and EU addresses. ESET found the toolset at government agencies in Kazakhstan and Romania and attributed it to Turla with high confidence, noting that it never observed attacker-controlled infrastructure. Exchange admins should check for DLLs disguised as Windows components in System32\wbem, unexpected Microsoft.Exchange.\*.ni.dll files in the .NET native image cache, and EdgeTransport.exe loading assemblies that aren't registered as transport agents.

[### installctl (GitHub Repo)](https://github.com/yamixst/installctl?utm_source=tldrinfosec)

installctl runs a curl | sh installer inside unprivileged namespaces on top of a FUSE copy-on-write overlay, then lists every file the installer created, changed, or deleted so you can apply all of it, some of it, or none. It pauses on package installs, new user accounts, systemctl calls, and crontab edits and asks whether to skip them, run them, or abort. Afterward, it writes an uninstall script that reverts only the installer's own edits to files like ~/.bashrc.

### Miscellaneous

[### Ransomware Recovery Is Now a Client Retention Metric (3 minute read)](https://www.bleepingcomputer.com/news/security/ransomware-recovery-is-now-a-client-retention-metric/?utm_source=tldrinfosec)

During a ransomware or other security incident, an MSP's clients may experience disruptions that lead to an erosion of trust and ultimately hurt client retention. Disorganized tools and handoffs can complicate recovery, while poor client communication and accounting can hurt trust. MSPs should track time to first client contact, time to recovery, and time to invoice as metrics in a successful recovery process.

[### A New AI Tool From Google DeepMind Proved the Signal Protocol Is Secure (5 minute read)](https://www.wired.com/story/a-new-ai-tool-from-google-deepmind-formally-verified-the-signal-protocol/?utm_source=tldrinfosec)

Researchers from Google DeepMind utilized a new agentic tool, AlphaProof Code, to formally verify several of the Signal protocol's cryptographic guarantees.
