### Attacks & Vulnerabilities

[### Critical binary-parser Flaw Enables JavaScript Injection via Malicious Parser Definitions (1 minute read)](https://thehackernews.com/2026/11/critical-binary-parser-flaw-enables.html?utm_source=tldrinfosec)

binary-parser versions before 2.3.1 contain CVE-2026-134814, a code-injection flaw with CVSS scores of 9.2 and 8.1. An attacker who controls parser definitions can inject JavaScript through unvalidated string options, including length, lengthInBytes, key, tag, offset, and namely() aliases. The code runs in the Node.js process when the parser compiles. Parsing untrusted binary data with a trusted definition is unaffected. Update to 2.3.1 or later.

[### VirtualBox Process Hardening on Windows 2026 Edition: What's a Single Bit Between Friends? (12 minute read)](https://projectzero.google/2026/11/virtualbox-process-hardening.html?utm_source=tldrinfosec)

Clearing a single bit, the IMAGE\_FILE\_EXECUTABLE\_IMAGE flag in a .NET assembly's PE header, makes NtCreateSection reject the file while the .NET Framework still loads it through a flat-image fallback that skips code integrity checks. Project Zero's James Forshaw used this to load untrusted code into hardened VirtualBox processes (CVE-2026-87268), bypass UMCI on Windows 11 S Mode through regasm.exe (CVE-2026-108398), and get TCB-level PPL code execution without admin rights by hijacking a COM object. Microsoft fixed the WLDP check in October, but the PPL bypass remains outside MSRC's servicing criteria, so defenders running WDAC should also enable the Dynamic Code Security option, which blocks the attack.

[### Critical Cisco remote code execution bug under attack (1 minute read)](https://www.theregister.com/security/2026/11/23/critical-cisco-remote-code-execution-bug-under-attack/5311722?utm_source=tldrinfosec)

Attackers exploited CVE-2026-76466 in clustered Cisco Expressway-C and Expressway-E gateways. The flaw uses hard-coded credentials and weak certificate validation to gain unauthenticated root command execution. F6 observed two internet-facing devices compromised, then accessed two internal cluster nodes as attackers deployed Python scripts for SMB discovery, SQL Server and WinRM interaction, and GitLab credential searches. CISA added the 9.8-CVSS bug to its Known Exploited Vulnerabilities catalog and set a Monday patch deadline for federal agencies.

### Strategies & Tactics

[### Things LLMs Get Wrong About AWS IAM (5 minute read)](https://engseclabs.com/blog/things-llms-get-wrong-about-aws-iam/?utm_source=tldrinfosec)

Writing AWS IAM permissions requires wading through a complex set of nuances. This post highlights three common anti-patterns that coding agents frequently trip over while writing policies. Agents often overuse Deny policies and permission boundaries, as well as unnecessarily include Allow statements for sts:GetCallerIdentity, which can never be denied.

[### Sandboxing AI Coding Agents: nono vs Docker Sandboxes vs Microsandbox vs OpenShell (18 minute read)](https://kudelskisecurity.com/research/sandboxing-coding-agents?utm_source=tldrinfosec)

Kudelski Security tested nono, Docker Sandboxes, Microsandbox, and NVIDIA OpenShell for running AI coding agents safely. All four scored 4 to 4.5 out of 5. Docker Sandboxes and Microsandbox use microVMs, nono uses OS-level controls and starts fastest, and OpenShell supports several isolation backends. The review covers filesystem limits, network filtering, DNS rebinding, credential injection, resource controls, logging, and agent-specific profiles. Only nono and OpenShell scope credentials to both a domain and an endpoint. None can deny a file inside an allowed directory or customize allowed syscalls.

[### Supply Chain Compromise Backdoors Six WP Connect Plugins, Blocked by WordPress.org's Release Hold (10 minute read)](https://www.wordfence.com/blog/2026/11/supply-chain-compromise-backdoors-six-wp-connect-plugins-blocked-by-wordpress-orgs-release-hold/?utm_source=tldrinfosec)

An attacker used WP Connect's own WordPress.org account to push backdoored releases of six plugins, including Air WP Sync and WP Sync for Notion, within about two hours. Each release added a fake "analytics and auto-update" module that checked in to tascredit-pay[.]com on every request with TLS verification turned off, ran whatever PHP the server sent back through eval(), and could also run shell commands, dump password hashes, and plant webshells. WordPress.org's new release cooling-off period under Protect The Shire stopped the updates before any site got them, and the developer says the account was compromised. However, admins should still check for the affected versions (CVE-2026-135202), remove them, and scan their sites for webshells and rogue WP-Cron hooks.

### Miscellaneous

[### BadBox 3.0 Ad Fraud Operation Generating 40 Billion Daily Bid Requests Disrupted (3 minute read)](https://www.securityweek.com/badbox-3-0-ad-fraud-operation-generating-40-billion-daily-bid-requests-disrupted/?utm_source=tldrinfosec)

Human Security disrupted BadBox 3.0, an ad-fraud botnet on backdoored, uncertified Android devices. At peak, it produced about 40 billion daily bid requests and over 4% of observed CTV traffic. Hidden modules spoofed legitimate apps, rendered invisible video ads, and enrolled devices in 11 residential proxy networks. Researchers linked parts of the operation to Chinese manufacturer TXCZ and to infrastructure disrupted during Google's XCPE takedown.

[### AI Agents Zip From Flaw Discovery to Root Access in 11 Minutes (3 minute read)](https://www.darkreading.com/cyberattacks-data-breaches/ai-agents-flaw-discovery-root-access-11-minutes?utm_source=tldrinfosec)

A China-linked actor used Cairn agents against East Asian universities for about 48 hours. The agents ran 148 actions against an exposed Redis server, tested over 30,000 SSH credential combinations against a GPU server, then found a path-traversal flaw in an open source medical imaging application. They wrote arbitrary files and ran a Python reverse shell as root within 11 minutes.

[### CrowdStrike to Acquire Zscaler, Bringing Network Security and Zero Trust to the Falcon Platform (7 minute read)](https://www.crowdstrike.com/en-us/press-releases/crowdstrike-to-acquire-zscaler-bringing-network-security-and-zero-trust-to-the-falcon-platform/?utm_source=tldrinfosec)

CrowdStrike has agreed to buy Zscaler in an all-stock deal that values it at about $43.9 billion, a roughly 34% premium, which puts CrowdStrike into network security by bringing Zscaler's Zero Trust SASE onto the Falcon platform. The combined company expects to start with more than $10 billion in ARR and to feed device and network telemetry into a single data set, which CrowdStrike pitches as the control plane for securing AI agents. Those synergy and market-size figures are the companies' own projections, and the deal is expected to close in the second half of CrowdStrike's fiscal 2028, pending Zscaler shareholder and regulatory approval, with Jay Chaudhry continuing to lead Zscaler.
