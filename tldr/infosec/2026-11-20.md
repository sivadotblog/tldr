### Attacks & Vulnerabilities

[### Ruby2ßhell (2 minute read)](https://verialabs.com/ruby2shell/?utm_source=tldrinfosec)

Researchers from Veria discovered a one-byte heap overflow vulnerability in Ruby. The vulnerability stems from a bug where Ruby's single-byte encodings upcase ß as SS, but the loop only checks for one. GitHub Enterprise Server, GitLab, and other popular software are affected.

[### Critical Apache Roller RCE Flaw Under Active Exploitation, No Authentication Required (2 minute read)](https://thehackernews.com/2026/11/critical-apache-roller-rce-flaw-under.html?utm_source=tldrinfosec)

Apache Roller versions 4.0.0 through 6.1.4 have an unauthenticated deserialization flaw in the XML-RPC endpoint that allows remote attackers to execute arbitrary code. It is being actively exploited. Users should upgrade to Roller 6.1.6 or later. If patching is delayed, set enabledForExtensions to false in WEB-INF/web.xml, remove the /roller-services/xmlrpc servlet mapping, and restart Roller. Disabling XML-RPC in the admin UI does not prevent exploitation on older versions.

[### PHP Fixes 7 Critical Flaws, Including Bugs That Could Allow Remote Code Execution (3 minute read)](https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html?utm_source=tldrinfosec)

Following a preemptive notice, the PHP Foundation released a security advisory and updates to fix seven critical vulnerabilities. Depthfirst codenamed one of the vulnerabilities phpAfterShell and developed a PoC that demonstrated how it can be exploited to create an arbitrary deserialization primitive which, when chained with another deserialization-to-RCE vulnerability, can lead to arbitrary code execution. The vulnerability affects any application that runs an affected PHP version with file-based sessions.

### Strategies & Tactics

[### Security Logging in Cloud Environments - Kubernetes (11 minute read)](https://blog.marcolancini.it/2026/blog-security-logging-cloud-environments-kubernetes/?utm_source=tldrinfosec)

Marco Lancini outlines the various log sources that are available for Kubernetes environments and their uses. Lancini also highlights blind spots such as events from on the node, API events that are sent directly to the kubelet instead of via the API server, and events from within a kubetctl exec shell. The post concludes by walking through a practical setup.

[### EggStreme Malware: Rebuilt Under Scrutiny (9 minute read)](https://businessinsights.bitdefender.com/eggstreme-malware-revises-architecture-infrastructure?utm_source=tldrinfosec)

Bitdefender reports that the EggStreme operators rebuilt Fuel, Loader, and Agent after its September 2025 disclosure. Fuel now uses AES-256-CBC encryption for its configuration. Loader payloads use RC5 or custom CBC ciphers. Agent traffic moved from gRPC to raw TCP over mutual TLS, with AES-256-CBC added. New commands enumerate Active Directory users, groups, and servers, run WMI with supplied credentials, impersonate user tokens, load .NET assemblies, and run PowerShell in memory. Some builds listen on TCP 5060 and add a firewall rule named “Core Networking - SIP.” The operators moved toward campaign-specific certificate authorities. Bitdefender assesses with high confidence that Philippine government organizations remain targets, with multiple victims; it assesses Taiwan targeting at low to medium confidence.

### Miscellaneous

[### Rakuten Securities Warns of Data Leak for 4.47M Accounts (2 minute read)](https://www3.nhk.or.jp/nhkworld/news/20261117de77429/?utm_source=tldrinfosec)

Japanese online brokerage Rakuten Securities says customer data for approximately 4.47M accounts may have leaked following unauthorized access. The breached data includes users' annual income, financial assets, means, dates of birth, employers, and financial products. Login IDs and account-identifying codes may also have been leaked for 11.25M accounts.

[### Muse Privacy Invasions Are Freaking Out Meta Staffers, Internal Chats Show (4 minute read)](https://arstechnica.com/tech-policy/2026/11/muse-privacy-invasions-are-freaking-out-meta-staffers-internal-chats-show/?utm_source=tldrinfosec)

Internal Meta chats show staff worried Muse accessed encrypted Signal messages, mixed conversations across accounts, and produced unsolicited outputs. One tester said Muse enrolled them in an $888-per-month insurance plan. Reuters found Muse could read Signal messages on Android through setup permissions and use macOS accessibility tools to retrieve messages. Meta calls the account-mix reports hallucinations and says the bug is fixed.

[### British Hackers Face Prison for GTA 6 Data Breach and Crypto Thefts (1 minute read)](https://techcrunch.com/2026/11/18/british-hackers-face-prison-for-gta-6-data-breach-and-crypto-thefts/?utm_source=tldrinfosec)

Tyler Buchanan received six years in a US court for a phishing scheme that stole at least $11 million in cryptocurrency from dozens of companies. Attackers impersonated IT helpdesks, obtained employee credentials, and accessed corporate systems. Arion Kurtaj admitted to attacks including stealing and extorting Rockstar Games and leaking GTA VI footage. Both belonged to overlapping groups known as 0ktapus, Lapsus$, and Scattered Spider, which targeted Coinbase, DoorDash, Mailchimp, and Nvidia.
