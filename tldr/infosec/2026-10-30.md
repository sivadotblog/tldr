### Attacks & Vulnerabilities

[### HHS Filing Puts iRhythm Data Breach Toll at 8.2 Million (2 minute read)](https://www.securityweek.com/hhs-filing-puts-irhythm-data-breach-toll-at-8-2-million/?utm_source=tldrinfosec)

In June, hackers accessed iRhythm's third-party-hosted business applications, demanded a ransom, and threatened to leak stolen data. HHS now lists 8,179,772 people as affected. Exposed data includes names, contact details, dates of birth, account and device identifiers, insurance numbers, and service dates. iRhythm says it has no evidence of identity theft and found no impact on medical devices, patient safety, manufacturing, or customer connections.

[### Leak Website Releases Data on Thousands of U.S. Homeland Security Employees (2 minute read)](https://www.reuters.com/legal/government/leak-website-releases-data-tens-thousands-dhs-employees-2026-10-28/?utm_source=tldrinfosec)

Distributed Denial of Secrets released data belonging to over 40K DHS employees. The data was obtained from an Okta instance, though Okta has stated that they were not breached. The stolen data includes DHS employees' names, phone numbers, and email addresses.

[### Linux Kernel TCP Flaw With 9.8 CVSS Score Affects Ubuntu, Red Hat, and Other Distributions (2 minute read)](https://thehackernews.com/2026/10/linux-kernel-tcp-flaw-with-98-cvss.html?utm_source=tldrinfosec)

Researchers from Anthropic uncovered a new use-after-free vulnerability in the Linux kernel that could lead to memory corruption, kernel memory reads, or system crashes. The vulnerability stems from a race condition in the TCP handshake and is fixed by ensuring all other CPUs finish reading the socket options before freeing them. Red Hat and other distros rate the vulnerability less severely because the race condition is complex to exploit.

### Strategies & Tactics

[### Google announces Gemini 4 Carbon, its latest frontier AI model that you can't use (3 minute read)](https://arstechnica.com/ai/2026/10/google-announces-gemini-4-carbon-its-latest-frontier-ai-model-that-you-cant-use/?utm_source=tldrinfosec)

Google announced Gemini 4 Carbon two weeks after Gemini 4 Argon. It targets vulnerability detection, validation, remediation, and secure code generation. Google says Carbon is twice as likely as Argon to produce vulnerability-free code and resisted all prompt-injection attempts in Grey Swan testing.

[### Threat Hunting for Malicious IP-KVM Usage (7 minute read)](https://nebulock.io/blog/threat-hunting-for-malicious-ip-kvm-usage?utm_source=tldrinfosec)

IP-KVM devices like PiKVM let remote operators drive a machine at the hardware layer with input indistinguishable from a local user, a tactic North Korean IT workers used to control laptop farms. Nebulock's hunt guide treated its sparse-peripheral and onboarding-timing heuristics as triage signals rather than attribution, since product strings and VID/PIDs can be spoofed. Threat hunters should search USB telemetry for known KVM vendors, then flag rare composite HID devices that also expose storage, networking, or video, and correlate hits with new-hire timing and identity anomalies before escalating to physical inspection.

[### Securing Internet-Critical Software: How We Could Have Backdoored Bash (7 minute read)](https://www.hacktron.ai/blog/hacking-gnu-savannah?utm_source=tldrinfosec)

GNU Savannah's Savane forge passed a user's email address unescaped into a shell command during GPG key testing, so an RFC-valid address containing backtick-wrapped commands gave any registered user code execution on the backend. Hacktron researchers used that foothold to read database credentials, grant themselves superuser, and impersonate Bash maintainer Chet Ramey, which exposed an SSH key page that would have allowed pushes to upstream Bash, before an unpatched GameOver(lay) kernel bug gave them root and a key to a GNU backup server. The FSF fixed all 26 reported flaws, and forge operators should pass process arguments as arrays rather than shell strings, treat email local parts as untrusted input, and verify that LTS kernels actually receive backported fixes.

### Launches & Tools

[### GitHub package firewall in public preview (2 minute read)](https://github.blog/changelog/2026-10-20-github-package-firewall-in-public-preview/?utm_source=tldrinfosec)

GitHub launched a package firewall in public preview for GitHub Enterprise Cloud, including data-resident deployments. It sits between coding agents, CI/CD hosts, and upstream registries, inspecting npm metadata requests and package downloads. Administrators can set cooldown periods, check GitHub Advisory Database advisories, and block attestation downgrades. Blocked packages can receive exceptions through a request workflow. The preview is free - general availability will use metered billing.

[### Vulnerator AI (GitHub Repo)](https://github.com/irraz/vulnerator-ai?utm_source=tldrinfosec)

Vulnerator AI runs a pentest as an OODA loop: Nous Research's Hermes agent picks the next tool and runs it on a Kali container through MCP, with nmap, nuclei, ffuf, sqlmap, and Prowler on hand. Unlike most agentic pentest frameworks, it drops the orchestration core, REST API, and UI. That leaves four containers, including a headless Playwright browser for web testing and an MCP front door that lets Claude Code or other clients start, steer, and stop runs. Mistral Large 4 on OpenRouter drives the loop by default and falls back to GLM-5.3 Flash, and local Ollama inference is documented as an option.

[### Project Quarry (GitHub Repo)](https://github.com/cisco-ai-defense/project-quarry?utm_source=tldrinfosec)

Project Quarry is a Python framework for detecting threats and behavior patterns in agent conversations. Write rules over messages, tool calls, tool results, and event order. You can also call a configured model adapter from a rule when local checks are not enough.

### Miscellaneous

[### Attacker Impersonates AI Bots to Scan Orgs for Keys, Credentials (3 minute read)](https://www.darkreading.com/cyber-risk/attacker-impersonates-ai-bots-scans-credentials?utm_source=tldrinfosec)

A scanner has impersonated 32 AI bots from OpenAI, Anthropic, Perplexity, Meta, and other providers since late September. It sends bursts of 50–190 requests, probes about 90 paths, and seeks passwords, API keys, cloud credentials, configuration files, and private SSH keys. On one October day, 48% of Cequence-protected organizations received the traffic. Most requests were blocked or failed.

[### Japan Airlines Warns of Data Breach as Country Grapples With Multiple Cyber Incidents (2 minute read)](https://therecord.media/japan-airlines-warns-of-breach-country-grapples-with-incidents?utm_source=tldrinfosec)

Japan Airlines is notifying 92K customers of a data breach exposing their data. The breach came through a third party that runs Japan Airlines' reservation, ticketing, and check-in systems. For most customers, the attackers retrieved only names, reservation codes, and flight information. However, for about 2,000 customers, they also retrieved passport numbers, frequent flyer numbers, email addresses, and phone numbers.

[### OpenAI Says It Will No Longer Train Its AI Models on the Live Internet, Citing ‘Significant Risks' (2 minute read)](https://techcrunch.com/2026/10/23/openai-says-it-will-no-longer-train-its-ai-models-on-the-live-internet-citing-significant-risks/?utm_source=tldrinfosec)

After multiple instances of OpenAI models accidentally attacking unauthorized sites in tests, the frontier lab announced it will cut models' internet access during training. Previously, OpenAI employees had said this would be infeasible. However, OpenAI announced that they will create a cached and indexed version of the public internet for model training.
