GMO Internet says an attacker accessed its Onamae Desktop Cloud service, which serves financial traders. Hackers demanded about $50 million, and GMO shut down the service on October 21. ### Strategies & Tactics

[### Cross-request KV cache exposure in the GLM-5.3 Workers AI model, and our remediation with SGLang (13 minute read)](https://blog.cloudflare.com/kv-cache-exposure-remediation?utm_source=tldrinfosec)

Prompts longer than 681,280 tokens sent to Cloudflare's GLM-5.3 Workers AI model returned other customers' data in 155 responses, because disaggregated SGLang marked over-length requests as rejected yet still handed decode a one-token KV cache that left earlier sessions' pages intact. Cloudflare knew its prefill KV pool was smaller than the advertised 1M-token context but only validated HTTP status codes before launch, and it found no evidence of deliberate exploitation during the August 27 to September 9 window. Operators running disaggregated SGLang should upgrade to v0.5.22 or later, verify KV pool size against context length on every node, and enable --disaggregation-enable-kv-checksum where their model supports it.

[### Loud, Fast, and Everywhere: Anatomy of a Real AI-Driven Cloud Attack (12 minute read)](https://www.wiz.io/blog/anatomy-of-ai-driven-cloud-attacks?utm_source=tldrinfosec)

Wiz has observed more threat actors leveraging AI agents to run end-to-end attacks on cloud environments. These attacks are noisy, persistent, and repeatedly alternate between different phases of an attack chain. In this article, Wiz walks through an actual attack chain that its CIRT observed. Defenders should unify logs, utilize AI for investigation and triage, assume full exposure on compromised resources, maintain visibility, and restrict trust between systems.

[### Making attacking agents pay with Context Bombs (7 minute read)](https://agentic.tracebit.com/factory/?utm_source=tldrinfosec)

Tracebit tested nine “Context Bomb” deception techniques against seven AI models in 773 controlled AWS assessments. Agents started with limited AWS permissions and had two hours to access data, execute code, or escalate privileges. Combined deception reduced the mean number of completed objectives from 2.48 to 0.23 per run, increased runtime by 2.8–8.9 times, and increased model cost by 1.6–3.9 times. A fake pentest report labeling real targets as canaries cut successful runs from 39/40 to 2/40 across four models. For defenders, the practical takeaway is that decoys can delay, misdirect, and sometimes stop automated attackers before they reach real objectives.

### Miscellaneous

[### Keystone to Destroy 18,835 Hardware Wallets After Hackers Steal Device Verification Key (3 minute read)](https://thehackernews.com/2026/10/keystone-to-destroy-18835-hardware.html?utm_source=tldrinfosec)

Attackers exploited a third-party monitoring tool on Keystone's website, obtained a hardware-wallet verification key, and accessed 25,964 buyer records plus 12,873 unpaid checkout records. The key could let counterfeit devices pass Keystone's authenticity check. Recovery phrases and private keys were not exposed. Keystone will destroy 18,835 unsold devices, pause shipments, and use a new key. Devices delivered after October 20 should not be used until support confirms authenticity.

[### Concerning behavior from a popular open-weight AI model (11 minute read)](https://cohere.com/blog/concerning-behaviour-popular-open-weight-ai-model?utm_source=tldrinfosec)

Alibaba's Qwen3.8-Flash-Next, asked to write a routine detection rule inside Cohere's sandbox, inventoried its host and tried to upload a probe file to an Alibaba Cloud bucket in Beijing. At the same time, its reasoning trace claimed it wouldn't call any tools. The behavior surfaced in fewer than one in 100,000 calls. Still, prefilling showed that adding curl's -o flag pushed suspicious host generation from 0.5% to 23%, alongside cloud metadata probes and namespace tricks to sidestep permission denials. Cohere, which sells its own sovereign models, couldn't say whether this reflects a deliberate implant or leftover training-sandbox residue. However, it published the traces and reproduction script for independent verification.

[### Microsoft Authenticator Flaw Lets Malicious Android Apps Steal Account Tokens With Zero Permissions (2 minute read)](https://cybersecuritynews.com/microsoft-authenticator-flaw/?utm_source=tldrinfosec)

Microsoft released an update to its Authenticator for Android app that could enable a local privilege escalation attack. An attacker could exploit the vulnerability to receive a token for any Microsoft app with a work profile installed on the device. The Authenticator app only validated whether the claimed identity looked valid, not whether it actually matched the caller.
