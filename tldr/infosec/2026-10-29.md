### Attacks & Vulnerabilities

[### Code-execution flaw in UEFI firmware affects most servers on planet Earth (7 minute read)](https://arstechnica.com/security/2026/10/code-execution-flaw-in-uefi-firmware-threatens-most-servers-on-planet-earth/?utm_source=tldrinfosec)

A 16-year-old buffer overflow in TianoCore EDK2's PXE Base Code driver (CVE-2026-97631, CVSS 9.5), the reference UEFI code behind most server firmware, allowed an attacker to send an oversized ICMP error during network boot and execute ring 0 code before Secure Boot and the TPM chain of trust loaded. An AMI pull request leaked the fix months ahead of a January coordinated disclosure, although exploitation required local network access and per-model address tuning. Defenders should request patched firmware from their UEFI vendors, disable PXE boot where feasible, and monitor network boot segments for anomalous ICMP traffic.

[### Sony ISP Subsidiary Data Breach Exposes 2.5M Customer Records (2 minute read)](https://www.bleepingcomputer.com/news/security/sony-isp-subsidiary-data-breach-exposes-25-million-customer-records/?utm_source=tldrinfosec)

Sony Network Communications disclosed that an unauthorized party accessed 2.5M records from its So-net member database, which supports its internet access service. The records included full names, phone numbers, email addresses, user IDs, dates of birth, gender, and Internet connection IDs. Additionally, it exposed 54K email addresses and account passwords from several email services.

[### Hackers Target US Election Commission, Forcing Online System Shutdown Days Before Midterms (2 minute read)](https://cybersecuritynews.com/hackers-target-u-s-election-commission-forcing-online-system-shutdown/?utm_source=tldrinfosec)

The Federal Election Commission (FEC) reported an outage in its filing system due to a cyberattack. The outage does not impact voting, just how campaigns report new funds flowing in. The FEC has not released details on whether any data was compromised.

### Strategies & Tactics

[### Not Only ARTEX: The Different Levels AI is Used in Attacks Targeting Japan (20 minute read)](https://www.trendaisecurity.com/en-us/resources-insights/deep-research/not-only-artex-the-different-levels-ai-is-used-in-attacks-targeting-japan?utm_source=tldrinfosec)

TrendAI examined three attacker infrastructures targeting Japan, documenting autonomous attacks, AI-assisted planning, and suspected AI-written tools. CyberStrikeAI coordinated 44 agents against at least 19 organizations. Another operator scanned 6,000 Japanese IPs and stole hundreds of thousands of records through default credentials. A third used recovered VPN credentials to enter corporate networks. Evidence came from exposed attacker files. Victim-side confirmation remains incomplete.

[### What are Security Logs? (6 minute read)](https://www.detectionengineering.net/p/what-are-security-logs-part-1?utm_source=tldrinfosec)

Logs are structured records of security events in formats such as JSON, CSV, Syslog, and Windows Event Logs. Security engineers need to apply transformations to event logs to normalize the various formats and fields, making the data uniform for correlation and composite detections.

[### How Anchorage Digital and Turnkey verify code with AWS Nitro Enclaves (12 minute read)](https://aws.amazon.com/blogs/architecture/how-anchorage-digital-and-turnkey-verify-code-with-aws-nitro-enclaves/?utm_source=tldrinfosec)

Anchorage Digital and Turnkey ran the open-source VisualSign transaction parser inside AWS Nitro Enclaves, where each parsed result was signed with an ephemeral P-256 key and bundled with a Nitro attestation document whose PCRs wallets checked against reproducible builds. The design let wallets prove that unmodified, audited code decoded a transaction, removing blind trust in crypto transaction signing by providing verifiable attestation rather than relying solely on network identity or operator trust. The open-source awsnitroverifier Go library handles certificate-chain and PCR validation, which any organization can use to verify their services running in AWS Nitro.

### Miscellaneous

[### Highway thieves are spoofing GPS to steal millions in data center-bound cargo (2 minute read)](https://arstechnica.com/tech-policy/2026/10/highway-thieves-are-spoofing-gps-to-steal-millions-in-data-center-bound-cargo/?utm_source=tldrinfosec)

Thieves have stolen over $100 million in data center equipment since June. They compromise freight accounts through malicious links, then bid on shipments using hijacked identities, and those with fake licenses get accomplices hired as drivers. Two thefts involved ramming security escorts' vehicles. One $10 million shipment disappeared after its tracking coordinates were apparently spoofed.

[### AI 'hacker' finds 4 severe bugs in popular industrial control software in under 4 hours (3 minute read)](https://www.theregister.com/security/2026/10/27/ai-hacker-finds-4-severe-bugs-in-popular-industrial-control-software-in-under-4-hours/5305811?utm_source=tldrinfosec)

Causal Security's Cipher found four EPICS Base vulnerabilities in three hours and 49 minutes. One critical integer overflow, rated CVSS 9.8, could enable remote code execution. Three high-severity flaws permit crashes, memory corruption, or information disclosure. Exploitation requires network access to vulnerable EPICS services. EPICS controls equipment including particle accelerators and fusion experiments.

[### American Organizations Under Attack: Skyw4lker Device Code Phishing Campaign Exposed (4 minute read)](https://thehackernews.com/2026/10/american-organizations-under-attack.html?utm_source=tldrinfosec)

Skyw4lker targets US manufacturing, technology, and healthcare organizations through device code phishing. Password-protected contracts or proposals send victims through Google Sites into legitimate Microsoft authentication flows. Completing attacker-initiated authorization gives attackers Microsoft 365 tokens. ANY.RUN identified obfuscated JavaScript and a PHP backend tracking victim sessions, IP addresses, and geolocation, and the backend repeatedly polls for authentication completion.
