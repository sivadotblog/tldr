### Attacks & Vulnerabilities

[### Hackers publish thousands of drivers' data after breaching Florida motor vehicle database (1 minute read)](https://techcrunch.com/2026/09/16/hackers-publish-thousands-of-drivers-data-after-breaching-florida-motor-vehicle-database/?utm_source=tldrinfosec)

ShinyHunters published hundreds of thousands of files stolen from Florida's DAVID vehicle and driver database after alleging the state agency refused to pay a ransom. FLHSMV confirmed that attackers used police credentials stored on a personal device. Leaked ownership records include names, addresses, buyer and seller details, and VINs. Some files also contain Social Security numbers, passports, and immigration documents.

[### First Agentic AI Data Breach Reported to Spanish Regulator (2 minute read)](https://www.securityweek.com/first-agentic-ai-data-breach-reported-to-spanish-regulator/?utm_source=tldrinfosec)

Spain's AEPD received a breach notification involving an automated system. It logged in, searched for flaws, changed personal data, and accessed invoices. Possible causes include a jailbroken model, an exposed test environment, or an unauthorized penetration-testing setup. The regulator calls for faster detection, containment, and response, plus stronger protection for digital identities and credentials.

[### Wordfence Argus Identifies Two Critical Unauthenticated Vulnerability Chains Leading to Remote Code Execution in The Events Calendar Plugin (6 minute read)](https://www.wordfence.com/blog/2026/09/wordfence-argus-identifies-two-critical-unauthenticated-vulnerability-chains-leading-to-remote-code-execution-in-the-events-calendar-plugin/?utm_source=tldrinfosec)

Two CVSS 9.8 flaws affect The Events Calendar up to version 6.17.4. Anonymous attackers can submit crafted Gutenberg markup in event comments and then trigger execution via pending-comment previews. One chain executes OS commands via PHP object injection, while the other resets an administrator password using wp\_update\_user. Update to 6.17.4.1. Exploitation requires comments enabled on event pages.

### Strategies & Tactics

[### Agentic Self-Modification in Open-Weights Systems (9 minute read)](https://www.irregular.com/research/agentic-self-modification-in-open-weights-systems?utm_source=tldrinfosec)

A coding agent fixed a failing query application by fine-tuning its shared Qwen model. It then merged the update into the default checkpoint, altering later agent and application instances, with held-out query accuracy rising from 0/20 to 20/20. The tuned model reproduced a synthetic API key, email, and address from training data and removed a trained refusal policy. Training tools, weight access, and deployment access increased modification attempts so as to track model lineage, retain training data and evaluations, and require approval before deployment.

[### Bring Your Own EDR: How to Turn a Commercial EDR into a Trojan Horse (10 minute read)](https://www.akamai.com/blog/security-research/bring-your-own-edr-turn-commercial-edr-trojan-horse?utm_source=tldrinfosec)

Researchers from Akamai discovered that attackers with admin access on a Windows device could abuse SentinelOne's EDR solution to dump protected processes, pivot to Microsoft Defender, and run malicious code in the Protected Process Light (PPL) context. They then extended this research by demonstrating how they could temporarily disable the EDR, move code into the EDR's protected files, run malicious code, and then re-enable the EDR, which would then protect the malicious code as part of its local files. Additionally, they found that cloud communication can be disabled by modifying the local DNS configuration.

[### How to Evaluate LLMs Before Production (12 minute read)](https://github.blog/ai-and-ml/llms/how-to-evaluate-llms-before-production/?utm_source=tldrinfosec)

When evaluating an LLM-based system to reduce false positives in GitHub secrets scanning, the team faced issues that made benchmarks unrepresentative of production workloads and prevented them from properly evaluating model performance. To combat this problem, the team at GitHub created an LLM evaluation framework. First, teams should define the product decision that the system should support; then teams should make sure that offline experiments use a representative dataset and have only one clearly defined variable; error analysis and LLM-as-judge systems can be used to guide human analysts towards interesting aspects of the evaluation; and then finally the experiment can be promoted to production.

### Miscellaneous

[### CISA Promotes a Fresh Way to Deter Cyberattackers: Lie to Them (2 minute read)](https://cyberscoop.com/cisa-guidance-cyber-decoys-critical-infrastructure/?utm_source=tldrinfosec)

CISA has published its first-ever guidance on setting up honeypot systems, accounts, and data to distract potential attackers and ultimately help discover them. The guidance comes from internal discussions with CISA threat hunters and pentesters who found that cyber decoys can be a low-cost, high-fidelity way to detect attackers who have gained access to a network.

[### $1 Million Sandbox Challenge Uncovers Linux Kernel Flaws (3 minute read)](https://www.securityweek.com/1-million-sandbox-challenge-uncovers-linux-kernel-flaws/?utm_source=tldrinfosec)

Vercel's two-week sandbox bounty received 1,285 reports and validated 92 findings, including one critical issue. No report accessed customer data. A leading submission chained two Linux networking flaws: one leaked host-kernel memory and another deterministically crashed the host. Patches remain under private review, and CVEs are pending.

[### Cisco Warns of Max Severity ISE Zero-Day Exploited in Attacks (2 minute read)](https://www.bleepingcomputer.com/news/security/cisco-warns-of-identity-service-engine-zero-day-exploited-in-attacks/?utm_source=tldrinfosec)

Cisco released security updates to address vulnerabilities in its Identity Services Engine, including a maximum-severity authentication bypass. An attacker could exploit the vulnerability to bypass authentication in the web-based management interface by sending a crafted request to affected endpoints. The Cisco PSIRT has identified this vulnerability as actively exploited and urges customers to update immediately.
