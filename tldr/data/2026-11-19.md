### Deep Dives

[### Agentic data engineering is here! Project Osmos: What, Why, and How? (22 minute read)](https://data-mozart.com/agentic-data-engineering-is-here-project-osmos-what-why-and-how/?utm_source=tldrdata)

Microsoft Fabric's Project Osmos is an AI agent that plans, builds, runs, and validates Spark data pipelines from a written specification. In a test using Vienna's public transit timetables, it built a working pipeline, but independent checks caught a daylight saving bug that the agent's own tests missed.

[### Rebuilding Data Lineage at LinkedIn: From Storage to Compute (15 minute read)](https://www.linkedin.com/blog/engineering/infrastructure/rebuilding-data-lineage-at-linkedin-from-storage-to-compute?utm_source=tldrdata)

LinkedIn rebuilt its data lineage platform to capture dependencies directly from running jobs, giving engineers a more precise view of where data comes from and what depends on it. The resulting graph covers about 6 million datasets and helps teams trace incidents, assess the impact of changes, and safely retire unused pipelines.

[### De-identifying text at scale: How Airbnb protects personal data in AI training (11 minute read)](https://medium.com/airbnb-engineering/de-identifying-text-at-scale-how-airbnb-protects-personal-data-in-ai-training-32f3ff8ff7d0?utm_source=tldrdata)

Training teams need realistic text data without letting PII leak into shared ML workflows. Airbnb packaged open-source Presidio, originally developed by Microsoft, as an in-process pipeline step, added domain-specific recognizers and multilingual evaluation, and then tagged de-identified datasets through its model registry. The useful pattern is turning privacy policy into testable, reusable data controls rather than asking every team to improvise.

[### MySQL tables in four open source Iceberg catalogs, read by Trino and DuckDB (5 minute read)](https://blog.dbtrail.com/mysql-tables-in-four-open-source-iceberg-catalogs-read-by-trino-and-duckdb/?utm_source=tldrdata)

Can MySQL changes land in Iceberg without a bespoke warehouse pipeline? DBTrail followed the binlog, exported initial and incremental snapshots into four open-source REST catalogs, then checked row counts and aggregates through Trino and DuckDB against MySQL. The tests surfaced real interoperability gaps around credential vending and equality deletes—not just a happy-path compatibility claim.

### Opinions & Advice

[### Are we Finally Entering the Golden Age of Data Science? (6 minute read)](https://medium.com/@tinyoli/are-we-finally-entering-the-golden-age-of-data-science-3b1ebf8b472c?utm_source=tldrdata)

AI and modern data tools are making it faster to build pipelines and answer routine business questions. This gives data scientists more time to ask questions that matter, design experiments, and use AI agents to test what actually drives business outcomes.

[### Data Contracts (32 minute read)](https://martinfowler.com/articles/data-contracts.html?utm_source=tldrdata)

Data contracts apply API design to datasets, describing their contents and guarantees so that people and AI agents can work with data on their own. A quality rule, such as less than 1% empty names, becomes an assertion that tooling can pass or fail. Published test results can then show how often each promise was kept.

[### pgvectorfast (GitHub Repo)](https://github.com/mitdbg/pgvectorfast?utm_source=tldrdata)

pgvectorfast is a drop-in replacement for pgvector that uses a faster buffer pool to speed up vector search and analytical queries in PostgreSQL.

[### Open Source DocumentDB 1.0 Reaches General Availability (3 minute read)](https://www.infoq.com/news/2026/11/mongodb-compatible-documentdb/?utm_source=tldrdata)

DocumentDB 1.0 brings an MIT-licensed, MongoDB-compatible document store to PostgreSQL through an extension and protocol gateway, letting existing drivers and queries work with a familiar relational foundation. The GA release covers PostgreSQL 15-18, adds a Kubernetes operator, and focuses on stability across indexing, aggregation, and geospatial queries.

[### MongoDB Acquires Firebolt (4 minute read)](https://www.mongodb.com/company/blog/news/mongodb-acquires-firebolt?utm_source=tldrdata)

MongoDB has acquired Firebolt and will run its analytics engine alongside the database, kept in sync automatically so there is no pipeline to build. MongoDB pitches it as removing the data-movement tax, since agents can drive thousands of concurrent queries and need sub-second answers on fresh data. It will join search, vector search, and Voyage AI models in the platform.

### Miscellaneous

[### How one SurrealQL query scans 10 billion rows a second (9 minute read)](https://surrealdb.com/blog/how-one-surrealql-query-scans-10-billion-rows-a-second?utm_source=tldrdata)

SurrealDB says its Earth database scanned more than 10 billion rows per second in a launch benchmark by splitting one query across about 1,000 Cloudflare Workers. Each worker reads a different slice of the same database snapshot, and SurrealDB checks and combines the results into one answer.

[### Airflow plays GTA2 (GitHub Repo)](https://github.com/vojay-dev/airflow-gta?utm_source=tldrdata)

This Apache Airflow 3.4 demo uses a local AI model to drive a car through a custom delivery mission in Grand Theft Auto 2. Each move is one iteration of an Airflow task loop, and a dashcam plugin lets you watch the run live or replay it later.

[### Securing Enterprise Data Agents with Policy as Code: A Preflight Gate for Multi-Domain NL2SQL (12 minute read)](https://blog.gopenai.com/securing-enterprise-data-agents-with-policy-as-code-a-preflight-gate-for-multi-domain-sql-63d4dee0e7d4?utm_source=tldrdata)

Shared service accounts can bypass the user-level controls a data agent is meant to enforce. This prototype parses generated SQL into an AST, resolves every table and column dependency, evaluates CEL policies, then prepares approved row filters before execution. Database roles remain the final guardrail. The takeaway: authorize the query's actual dependencies, not just its visible output.
