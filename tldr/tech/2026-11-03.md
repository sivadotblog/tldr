Apple is reportedly working on an AI-driven home robot potentially named the HomeView Ultra. It plans to launch the robotic product with a possible price tag of $1,000 or more by 2027. [### What Is Quantum Advantage Actually Worth? (9 minute read)](https://www.mackenziemorehead.com/what-is-quantum-advantage-actually-worth/?utm_source=tldrnewsletter)

Nearly all roadmaps point to a utility-scale quantum computer being developed around 2030. Despite this, there is little confidence or clarity on how these machines will actually be useful. The consensus is now that they'll first be used for breaking cryptography. The second most concrete answer is to use them to generate simulation data for AI labs' science models. This post looks at how else quantum computing could be applied and where all the revenue will come from.

[### Scaling Git at OpenAI (31 minute read)](https://openai.com/index/scaling-git-at-openai/?utm_source=tldrnewsletter)

OpenAI's monorepo's size and demands increased at a staggering pace over the last year, necessitating a revamp of the AI lab's source control system. Its technical staff built Pando, a new backend for Git repositories optimized for concurrent pushes to many branches and to maximize read throughput. The team implemented the backend without interrupting any engineering work or changing how the team uses Git. Pando cut median push latency in production by nearly 5x, and it now delivers nearly a petabyte of Git data per day.

[### Why Agents Are Soon Only Going to Have 1 Tool (9 minute read)](https://www.philschmid.de/code-mode?utm_source=tldrnewsletter)

Agents are collapsing their entire tool catalog into one 'exec' tool. This allows models to write short scripts that chain, combine, and await actions inside isolated sandboxes. Models can now reliably combine and chain dependent actions in a single pass. In the previous standard tool-calling model, agents could only perform single actions, but the exec tool allows them to perform multiple actions.

[### Our organizations are being DDoSed from the inside (6 minute read)](https://karrisaarinen.com/posts/our-organizations-are-being-ddosed-from-the-inside/?utm_source=tldrnewsletter)

Organizations are losing attention as everyone within is doing something they think is useful, but all that work draws on the same limited capacity to understand, review, and decide. Just because work exists doesn't mean it's the right thing to do. Output is not proof of value. A working implementation only means that something can be built, not that it should be - some changes have negative value.

[### The value of open source (16 minute read)](https://haydenbleasel.com/writing/open-source?utm_source=tldrnewsletter)

People open source projects for various reasons. Some do it to build a company or product, others do it performatively, and some ship code just for the love of the game. Open source was never free to copy, and the code was never the moat. AI can remake a product, but it can't provide the rest of the value a company generates. The technology is helping maintainers ship and fix problems faster.
