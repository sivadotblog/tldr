### Big Tech & Startups

[### Introducing the Agents API (5 minute read)](https://openai.com/index/introducing-the-agents-api/?utm_source=tldrnewsletter)

OpenAI's Agents API is now in public beta. The API brings the same harness and infrastructure that powers Codex to developers through a simple and flexible API. It allows developers to create useful agents with a powerful harness that manages context, uses tools efficiently, and coordinates subagents. The API provides infrastructure to keep agents running reliably for days, and environments where agents can work with files, run code, and save intermediate results.

[### Tech companies move to open AI models (8 minute read)](https://blog.pragmaticengineer.com/the-pulse-tech-companies-move-to-open-ai-models/?utm_source=tldrnewsletter)

Companies are experimenting with cheaper open models on inference providers. There is a trend toward more investment in model routing to route simpler requests to cheaper models. This post follows the journey of a PostgreSQL query through all of the layers of a complex sharded system. It aims to help readers understand what goes into making a large-scale sharded PostgreSQL deployment appear to be a single server even when spanning thousands of servers. A real database has hundreds of tables - the example in the post keeps the schema simple with two tables spread across four shards.

[### Router Power (14 minute read)](https://hypersoren.xyz/posts/router-power/?utm_source=tldrnewsletter)

Centralized router platforms can offer customers better economics than local deployments. Outcomes pricing belongs to the infrastructure layer. The model layer could offer outcomes pricing, but it will have the same problems as the app layer. Router layer pricing is most politically aligned with customers, who just want to sell more compute and don't care which model is used.
