### Science & Futuristic Technology

[### Hardware Is Software (13 minute read)](https://unchartedterritories.tomaspueyo.com/p/hardware-is-software?utm_source=tldrnewsletter)

Most hardware engineering is actually software engineering in disguise. Everything is a calculation, and calculation is software. The industry is currently doing these calculations essentially by hand, as if it were doing arithmetic without having yet discovered algebra. Hardware engineers need to design algorithms for designing their hardware. This allows small teams to build big things.

[### Unblockable communication with gravity (32 minute read)](https://www.science.org/doi/10.1126/sciadv.aee0802?utm_source=tldrnewsletter)

All modern wireless communication technologies are based on electromagnetism, which is readily susceptible to screening and blocking. Gravity is a viable platform for practically unblockable communication. This study proposes and implements a wireless communication protocol where a broadcaster encodes a binary message by moving a mass, and a receiver detects the resulting gravitational signal with an off-the-shelf, hand-held gravimeter.

[### AWS announces ExtendDB 1.0 (1 minute read)](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-extenddb-1-0/?utm_source=tldrnewsletter)

ExtendDB is a production-ready Amazon DynamoDB-compatible adapter. It is fully compatible with the DynamoDB API and can run on PostgreSQL, SQLite, Cassandra, and MongoDB. ExtendDB allows developers and infrastructure teams to run DynamoDB workloads in on-premise data centers, in private or public clouds, and at the edge, without rewriting application code. [### Foundation Software (5 minute read)](https://jacobtomlinson.dev/posts/2026/foundation-software/?utm_source=tldrnewsletter)

Open source projects are being flooded with PRs thanks to AI. Instead of submitting these PRs, developers should publish forks with no expectation of merging. Maintainers could then search through the forks and see what other people are building, then choose which changes to make upstream. This search could be done with agents hunting for patterns.
