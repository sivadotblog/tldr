### Deep Dives & Analysis

[### How to Train a Swarm (19 minute read)](https://www.gr.inc/blog/how-to-train-a-swarm?utm_source=tldrai)

Swarms are AI systems where multiple agents cooperate towards a shared goal. This post discusses a technique called collective inference-time scaling, where agents scale the amount of useful work performed in parallel and the communication needed to achieve it. It also explains how to design incentives for parallel work, and covers the general topic of designing incentives for reinforcement learning.

[### Lessons from building Copilot Cowork (21 minute read)](https://commandline.microsoft.com/how-we-built-copilot-cowork-python-to-rust-migration/?utm_source=tldrai)

Microsoft's Copilot Cowork, an AI-driven agentic execution layer, achieved global availability in four and a half months, switching its runtime from Python to Rust while live. Key practices included writing clear specs before coding, running narrow agents with clear boundaries, and ensuring automated checks genuinely verify code changes. The transition to Rust improved efficiency and highlighted the importance of clear testing, boundary setting, and human oversight in the development process.

[### The Hitchhiker's Guide to Training on Compute Islands (18 minute read)](https://www.coreauto.com/hitchhikers-guide-to-training-on-compute-islands?utm_source=tldrai)

Being able to train reliably on multiple smaller clusters widens the usable training pool for frontier training. A single run could mix accelerator generations and vendors as each island runs on its own schedule. Older generations or less common chips could also participate in a frontier run. One risk with this model is that integrity and safety may become harder when models are trained across providers, as one faulty or compromised site can quietly degrade or tamper with models in ways that are harder to trace.

[### Harness 2: executing agent code as it streams (6 minute read)](https://framer.com/blog/harness-2/?utm_source=tldrai)

Framer's Harness 2 significantly upgrades the agent's execution process, allowing entire workflows in one program, achieving up to 33% cost reduction and 20% faster execution. This is done by executing JavaScript as it streams in, avoiding multiple model calls and using eager execution and early cancellation to enhance efficiency. The redesign also replaces DSL with method calls for real-time updates, making task execution streamlined for both in-app and external agents, reducing tool steps by 43% and cached input tokens by 39% per message.
