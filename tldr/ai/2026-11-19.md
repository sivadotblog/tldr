### Deep Dives & Analysis

[### Why is Gemini 4 Carbon taking so long? (4 minute read)](https://kernel.dev/blog/why-is-gemini-4-carbon-taking-so-long/?utm_source=tldrai)

In a private benchmark, Gemini 4 Carbon spent close to an hour on bug fixes that Claude Opus 5.5 and GPT-6 Astra finished in minutes. Carbon took about seven times as many steps as Astra, and half were unnecessary.

[### Why Antigravity Eats Weekly Quota Fast - and What I Measured (17 minute read)](https://asubedi.com.np/blog/why-antigravity-eats-weekly-quota-fast/?utm_source=tldrai)

Google Antigravity wipes users' prompt caches if there is a 5-minute pause. Refreshing the cache just before expiry works, but only for 3 pings. Even a 5-word prompt starts with 13,800 to 16,800+ tokens of system instructions, MCP schemas, and skills. Disabling unused MCP servers and plugins shrinks cold turns and cache misses.

[### Switching LLMs mid-conversation is a ski-rental problem (30 minute read)](https://www.edgee.ai/blog/posts/switching-llms-mid-conversation-is-a-ski-rental-problem?utm_source=tldrai)

Most work on routing between language models is centered on making sure the right model handles the right request. A classifier scores the request, then the request is routed to a cheap model if it is easy, and a frontier model if it is hard. For coding agents, this is only half of the problem. The second half of the problem is knowing when a running session should change model. This problem, which this post discusses, has a classic form: the ski-rental problem.

[### Introducing Model Factory (8 minute read)](https://www.primeintellect.ai/blog/introducing-model-factory?utm_source=tldrai)

Model Factory is a training loop that lets any company train, deploy, and continuously improve models in production. It brings reinforcement learning, supervised fine-tuning, pre-training, and inference together into one control plane. It also offers health checks, automatic node replacement, and recovery from the latest checkpoint for long-running experiments. Model Factory has already been deployed for teams working on finance automation, computer use, scientific discovery, chip design, and other industries.
