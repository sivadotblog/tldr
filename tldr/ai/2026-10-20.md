### Headlines & Launches

[### MiniMax M3.1 Flash: Redefining Agent Performance and Cost (4 minute read)](https://www.minimax.io/blog/minimax-m31f?utm_source=tldrai)

MiniMax M3.1 Flash delivers a generational leap in agentic tasks, coding, Computer Use, and cybersecurity. It makes online inference nearly three times faster and reduces usage costs by 70%. The model is now available through the MiniMax API, M Plan, and MiniMax Code. MiniMax plans to release the model weights at a later date.

[### Mercury 3 (4 minute read)](https://www.inceptionlabs.ai/blog/introducing-mercury-3?utm_source=tldrai)

Inception Labs' Mercury 3 is a diffusion-based language model that reportedly outperformed GPT-6 Luna and Claude Haiku 5.5 on multiple benchmarks while generating over 1,000 tokens per second.

[### Introducing Clairic, a new System One class of extraction models (16 minute read)](https://blog.cloudflare.com/clairic-extraction-model?utm_source=tldrai)

Clairic can extract, compute, estimate, and forecast values from unstructured inputs. It is an 'extraction model', a new class of System One-style model that returns values directly extracted from the input, computed from it, or predicted beyond it. The model doesn't generate any tokens, so it can't produce a mistyped answer or hallucinate in the same way LLMs can. It can still make mistakes, but its outputs come with confidence scores to help users evaluate whether it is appropriate to trust the model or to take a second look.

[### Introducing TorchNeuron: Native PyTorch backend for AWS Trainium (27 minute read)](https://pytorch.org/blog/introducing-torchneuron-native-pytorch-backend-for-aws-trainium/?utm_source=tldrai)

TorchNeuron is an open-source native PyTorch backend for Trainium. It uses the model code, the libraries, and the tools developers already use on Trainium. TorchNeuron supports eager execution for research and debugging. It has been released in public Beta under the Apache 2.0 open source licence.

[### Introducing Exa 3.0 (3 minute read)](https://exa.ai/blog/exa-3?utm_source=tldrai)

Exa 3.0 leads on evaluations spanning coding, finance, deep research, and company intelligence. The release includes Exa Lite, a new search type priced at $4 per 1,000 requests. Exa runs its own crawler and an independent index, tracking over 2 trillion URLs, serving 100 billion pages, and growing around what its customers search for. The index includes 1.27B ecommerce listings with prices and availability, over 211 million local businesses with hours and ratings, real-time news, sports, weather, and market data, and information on flights, local events, transit, and podcasts.

[### Office Intelligence for Long-Running AI Work (3 minute read)](https://officeintelligence.github.io/?utm_source=tldrai)

Office Intelligence explores how AI agents can use evidence, create useful work artifacts, and carry knowledge across tasks. The project focuses on environments, datasets, and learning methods for sustained knowledge work.
